# Beatframe — foydalanish qo'llanmasi

## Beatframe Studio (veb-ilova) — asosiy usul

**Bir martalik sozlash:**
```bash
cd ~/Desktop/"YouTube content"/beatframe
bash studio.sh --install
```

**Keyin har safar ikki yo'ldan biri:**
- terminalda `studio` deb yozing;
- yoki ilovalar menyusidan **Beatframe Studio**'ni oching. Uni dock'ga ham mahkamlab qo'yish mumkin.

Ilova ishga tushadi va brauzerda `http://127.0.0.1:8000` o'zi ochiladi. Agar u allaqachon ishlab turgan bo'lsa, faqat brauzer ochiladi. To'xtatish uchun terminal oynasini yoping yoki `Ctrl+C` bosing.

1. **Studio** sahifasida: (1) loyiha nomi (ixtiyoriy), (2) **Video format** — **Short** (9:16, Shorts/Reels/TikTok uchun) yoki **Long** (16:9, oddiy YouTube video), (3) men bergan script'ni to'liq paste qiling. Matn yozilayotganda xatolar shu zahoti ko'rsatiladi.
2. **Generate Video** tugmasini bosing (Advanced settings'da preview / final / faqat yaratishni tanlash mumkin). Progress jonli ko'rinadi, preview tayyor bo'lgach video o'zi ochiladi.
3. Biror joy yoqmasa, **Edit beats** bo'limiga o'ting. U yerda gapni, sahnani va sozlamalarni o'zgartirasiz, keyin **Save & preview this beat** tugmasini bosib, faqat o'sha bo'lakni ko'rasiz. Beat'larni qo'shish (＋), o'chirish (✕) va tartibini almashtirish (↑ ↓) ham shu yerda.
4. **Script** bo'limida butun yaml'ni to'g'ridan-to'g'ri tahrirlash yoki yangi versiya bilan almashtirish mumkin.
5. Hammasi yoqqanda **Render final** tugmasini bosing. Formatni loyiha sahifasining tepasidagi **Long / Short** tugmasi bilan istalgan vaqtda almashtirish mumkin — ikkala format natijalari alohida saqlanadi (`final.mp4` va `final_short.mp4`).
6. **Publish** bo'limida ikki yo'l bor:
   - **Manual upload** — `final.mp4` va subtitrni yuklab olasiz, title va description'ni "copy" tugmasi bilan nusxalab, Studio'ga qo'yasiz. Bu har doim ishlaydi.
   - **Upload to YouTube** — dasturning o'zi yuklaydi: title, description, boblar, subtitr, muqova, ko'rinish va reja vaqti bilan. Bir martalik sozlash kerak, uning qadamlari sahifaning o'zida yozilgan. Muhim: Google loyihangiz YouTube API auditidan o'tmaguncha, API orqali yuklangan har bir video **Private** bo'lib qoladi.

Videolar va script'lar `projects/` papkasida saqlanadi, shuning uchun quyidagi terminal buyruqlari ham xuddi shu loyihalar bilan ishlaydi.

## Terminal orqali (ixtiyoriy)

## 0. Har safar boshlashda

```bash
cd ~/Desktop/"YouTube content"/beatframe
source .venv/bin/activate
```
Qator boshida `(.venv)` paydo bo'lsa, tayyor. `beatframe: command not found` chiqsa, ikkinchi qatorni unutgansiz.

## 1. Yangi video yaratish

```bash
beatframe new neanderthal --title "There's a Neanderthal Inside You"
```
`projects/neanderthal/neanderthal.yaml` fayli tayyor namuna bilan yaratiladi. Uni VS Code'da oching:
```bash
code projects/neanderthal/neanderthal.yaml
```

## 2. Script yozish (yaml fayl)

Har bir **beat** — narrator aytadigan bitta gap va uning ostidagi sahna:

```yaml
beats:
  - text: "Narrator aytadigan gap (inglizcha)."
    scene: statement                # qaysi shablon
    chapter: "Bob nomi"             # ixtiyoriy: YouTube bobi shu yerdan boshlanadi
    params: {text: "Ekranda chiqadigan matn.", highlight: "matn"}
```

Qoidalar:
- `text` — ovozga aylanadigan matn. Sahna uzunligi shu ovozga qarab avtomatik belgilanadi.
- Bitta beat'da 1–3 ta gap bo'lsin. Uzun paragrafni bir nechta beat'ga bo'ling: tasvir tez-tez almashib turadi, tomoshabin zerikmaydi.
- `scene` va `params` ro'yxatini ko'rish uchun:
  ```bash
  beatframe templates
  ```
- Bo'sh joylar (probel) muhim: `- text`, `scene`, `params` bir xil chiziqda turishi kerak.

```bash
beatframe check projects/neanderthal/neanderthal.yaml
```

Xato bo'lsa, qaysi beat'da va nima noto'g'ri ekanini yozadi. Masalan, shablon nomida xato bo'lsa, `unknown scene` chiqadi.

"""Kokoro voice worker. Runs in its own Python 3.12 environment (~/.kokoro), because Kokoro's
libraries don't install on newer Pythons yet. Beatframe starts it once and sends one JSON line per
beat: {"text": ..., "voice": "am_michael", "speed": 1.0, "out": "/path/001_k.wav"} -> replies "ok" or "error: ...".
"""
import json
import sys

import numpy as np
import soundfile as sf
from kokoro import KPipeline

OUT = sys.stdout          # answers go here; anything the libraries print goes to stderr
sys.stdout = sys.stderr


def say(msg: str) -> None:
    OUT.write(msg + "\n")
    OUT.flush()


pipes = {}
say("ready")
for line in sys.stdin:
    try:
        job = json.loads(line)
        lang = "b" if job["voice"].startswith("b") else "a"
        if lang not in pipes:
            pipes[lang] = KPipeline(lang_code=lang, repo_id="hexgrad/Kokoro-82M")
        parts = [a.numpy() if hasattr(a, "numpy") else a for _, _, a in pipes[lang](job["text"], voice=job["voice"], speed=job["speed"])]
        sf.write(job["out"], np.concatenate(parts), 24000)
        say("ok")
    except Exception as e:  # noqa: BLE001
        say("error: " + str(e).replace("\n", " "))

"""A tiny in-process job queue: one worker thread runs renders/uploads in order.

For a single user on a laptop this is all we need (no Redis). Render jobs get live
progress events from pipeline.run (stage, beat, done/total), so the page shows what the
pipeline is really doing; upload jobs report a 0-100 fraction.
"""

from __future__ import annotations

import queue
import threading
import time
import traceback
import uuid
from dataclasses import dataclass, field
from typing import Callable

# share of the progress bar each render stage owns (Manim rendering is the long part)
STAGE_SPAN = {"check": (0, 2), "voice": (2, 14), "render": (14, 90), "assemble": (90, 96),
              "extras": (96, 100), "done": (100, 100)}
STAGE_TEXT = {"queued": "Waiting in queue", "check": "Checking the script", "voice": "Generating voice",
              "render": "Rendering animation", "assemble": "Joining clips and audio",
              "extras": "Adding subtitles, chapters and thumbnails", "done": "Finished"}


@dataclass
class Job:
    id: str
    slug: str
    kind: str                     # preview | make | beat | upload
    label: str
    total: int = 1
    done: int = 0
    status: str = "queued"        # queued | running | done | failed
    fmt: str = "long"             # video format of a render job
    stage: str = "queued"
    beat: int | None = None       # beat being rendered right now
    template: str | None = None
    percent: float = 0.0
    lines: list[str] = field(default_factory=list)
    error: str = ""
    result: dict = field(default_factory=dict)
    created: float = field(default_factory=time.time)
    started: float | None = None
    finished: float | None = None

    @property
    def is_render(self) -> bool:
        return self.kind in ("preview", "make", "beat")

    @property
    def progress(self) -> float:
        if self.status == "done":
            return 1.0
        if self.is_render:
            return min(0.99, self.percent / 100)
        return min(0.99, self.done / max(self.total, 1))

    @property
    def stage_text(self) -> str:
        return STAGE_TEXT.get(self.stage, self.stage)

    @property
    def elapsed(self) -> int:
        if not self.started:
            return 0
        return int((self.finished or time.time()) - self.started)

    def log(self, msg: str) -> None:
        self.lines.append(msg)

    def on_progress(self, ev: dict) -> None:
        """Receives pipeline.run progress events."""
        stage = ev["stage"]
        self.stage = stage
        if "total" in ev:
            self.done, self.total = ev.get("done", 0), ev["total"]
        if stage == "render":
            self.beat, self.template = ev.get("beat", self.beat), ev.get("template", self.template)
        lo, hi = STAGE_SPAN.get(stage, (self.percent, self.percent))
        frac = self.done / self.total if stage in ("voice", "render") and self.total else 0.0
        self.percent = round(max(self.percent, lo + (hi - lo) * frac), 1)

    def steps(self) -> list[dict]:
        """The render checklist shown on the page: label, state (done|active|pending|failed), detail."""
        order = ["check", "voice", "render", "assemble"] + (["extras"] if self.kind == "make" else [])
        labels = {"check": "Check script", "voice": "Generate voice", "render": "Render scenes",
                  "assemble": "Combine with FFmpeg", "extras": "Subtitles, chapters & thumbnails"}
        cur = order.index(self.stage) if self.stage in order else (len(order) if self.stage == "done" else -1)
        out = []
        for i, key in enumerate(order):
            if self.status == "done" or i < cur:
                state = "done"
            elif i == cur:
                state = "failed" if self.status == "failed" else "active"
            else:
                state = "pending"
            detail = ""
            if key in ("voice", "render") and state in ("active", "failed") and self.stage == key and self.total:
                detail = f"{self.done}/{self.total}"
            out.append({"label": labels[key], "state": state, "detail": detail})
        return out


class JobManager:
    def __init__(self) -> None:
        self.jobs: dict[str, Job] = {}
        self.q: "queue.Queue[tuple[Job, Callable[[Job], dict | None]]]" = queue.Queue()
        threading.Thread(target=self._worker, daemon=True).start()

    def submit(self, slug: str, kind: str, label: str, total: int, fn: Callable[[Job], dict | None],
               fmt: str = "long") -> Job:
        job = Job(id=uuid.uuid4().hex[:10], slug=slug, kind=kind, label=label, total=total, fmt=fmt)
        self.jobs[job.id] = job
        self.q.put((job, fn))
        return job

    def latest(self, slug: str) -> Job | None:
        mine = [j for j in self.jobs.values() if j.slug == slug]
        return max(mine, key=lambda j: j.created) if mine else None

    def active(self, slug: str) -> Job | None:
        j = self.latest(slug)
        return j if j and j.status in ("queued", "running") else None

    def _worker(self) -> None:
        while True:
            job, fn = self.q.get()
            job.status, job.started = "running", time.time()
            if job.is_render:
                job.on_progress({"stage": "check"})
            try:
                job.result = fn(job) or {}
                job.status = "done"
                if job.is_render:
                    job.on_progress({"stage": "done"})
            except Exception as e:  # noqa: BLE001
                job.status = "failed"
                job.error = str(e) or e.__class__.__name__
                job.lines.append(traceback.format_exc(limit=3))
            finally:
                job.finished = time.time()
                self.q.task_done()


=== FAYL: ./beatframe/web/stats.py ===
"""Channel statistics as one compact text block, to paste into a Claude chat.

Uses the same OAuth login as uploads (CONFIG_DIR), so every Beatframe copy reads only
the channel it is connected to. Needs two things once:
  * "YouTube Analytics API" enabled in the same Google Cloud project as the Data API
  * the yt-analytics.readonly scope -> press "Reconnect YouTube" on the Stats page

YouTube's API does not expose thumbnail impressions or impressions CTR; those stay in Studio.
Analytics numbers lag about 2 days behind Studio's realtime view.
"""

from __future__ import annotations

import json
import re
from datetime import date, datetime, timedelta, timezone

from beatframe.web import youtube

ANALYTICS_SCOPE = "https://www.googleapis.com/auth/yt-analytics.readonly"
LAST = youtube.CONFIG_DIR / "stats_last.txt"
SHORT_MAX_SECONDS = 180   # YouTube treats vertical videos up to 3 min as Shorts


class StatsError(RuntimeError):
    """A problem the page should explain in plain words (not a crash)."""


def has_scope() -> bool:
    """True when the saved login already allows reading YouTube Analytics."""
    try:
        data = json.loads(youtube.TOKEN.read_text(encoding="utf-8"))
    except Exception:  # noqa: BLE001
        return False
    scopes = data.get("scopes") or data.get("scope") or []
    if isinstance(scopes, str):
        scopes = scopes.split()
    return ANALYTICS_SCOPE in scopes


def last_report() -> dict:
    if not LAST.exists():
        return {}
    return {"text": LAST.read_text(encoding="utf-8"),
            "when": datetime.fromtimestamp(LAST.stat().st_mtime).strftime("%d %b %H:%M")}


# ----------------------------------------------------------------- helpers
def _secs(iso: str) -> int:
    """ISO-8601 duration (PT1M5S) -> seconds."""
    m = re.fullmatch(r"P(?:(\d+)D)?T?(?:(\d+)H)?(?:(\d+)M)?(?:(\d+)S)?", iso or "")
    if not m:
        return 0
    d, h, mi, s = (int(x or 0) for x in m.groups())
    return ((d * 24 + h) * 60 + mi) * 60 + s


def _mmss(s: float | int | None) -> str:
    s = int(round(s or 0))
    return f"{s // 60}:{s % 60:02d}"


def _age(published: datetime, now: datetime) -> str:
    h = (now - published).total_seconds() / 3600
    return f"{int(h)}h" if h < 48 else f"{int(h // 24)}d"


TRAFFIC_NAMES = {
    "SHORTS": "Shorts feed", "YT_SEARCH": "YouTube search", "RELATED_VIDEO": "Suggested", "SUBSCRIBER": "Browse/home",
    "YT_CHANNEL": "Channel page", "YT_OTHER_PAGE": "Other YouTube", "EXT_URL": "External", "NO_LINK_OTHER": "Direct/unknown",
    "PLAYLIST": "Playlists", "YT_PLAYLIST_PAGE": "Playlist page", "NOTIFICATION": "Notifications", "END_SCREEN": "End screens",
    "HASHTAGS": "Hashtags", "SOUND_PAGE": "Sound page",
}


def _n(x) -> str:
    return f"{int(x):,}" if x is not None else "-"


def _query(ya, **kw) -> list[dict]:
    """Run an Analytics query and return rows as dicts."""
    res = ya.reports().query(ids="channel==MINE", **kw).execute()
    cols = [c["name"] for c in res.get("columnHeaders", [])]
    return [dict(zip(cols, r)) for r in res.get("rows", []) or []]


def _per_video(ya, start: str, end: str) -> tuple[dict, bool]:
    """Lifetime numbers per video. engagedViews is newer; fall back without it if refused."""
    base = "views,estimatedMinutesWatched,averageViewDuration,averageViewPercentage,likes,subscribersGained"
    for metrics, engaged in ((base + ",engagedViews", True), (base, False)):
        try:
            rows = _query(ya, startDate=start, endDate=end, metrics=metrics, dimensions="video",
                          sort="-views", maxResults=200)
            return {r["video"]: r for r in rows}, engaged
        except Exception as e:  # noqa: BLE001
            if engaged and "engagedViews" in str(e):
                continue
            raise
    return {}, False


# ------------------------------------------------------------------ report
def build_report(days: int = 28, max_videos: int = 60) -> str:
    """Fetch the connected channel's numbers and return the text block."""
    from googleapiclient.discovery import build
    from googleapiclient.errors import HttpError

    creds = youtube._creds()  # noqa: SLF001
    if not creds:
        raise StatsError("YouTube is not connected. Press Connect YouTube first.")
    if not has_scope():
        raise StatsError("The YouTube login does not allow statistics yet. Press Reconnect YouTube.")

    try:
        yt = build("youtube", "v3", credentials=creds, cache_discovery=False)
        ya = build("youtubeAnalytics", "v2", credentials=creds, cache_discovery=False)

        ch = yt.channels().list(part="snippet,statistics,contentDetails", mine=True).execute().get("items", [])
        if not ch:
            raise StatsError("This Google account has no YouTube channel.")
        ch = ch[0]
        cid, title = ch["id"], ch["snippet"]["title"]
        subs = ch.get("statistics", {}).get("subscriberCount", "?")
        uploads = ch["contentDetails"]["relatedPlaylists"]["uploads"]
        created = ch["snippet"]["publishedAt"][:10]

        # newest uploads first
        ids, token = [], None
        while len(ids) < max_videos:
            r = yt.playlistItems().list(part="contentDetails", playlistId=uploads, maxResults=50,
                                        pageToken=token).execute()
            ids += [i["contentDetails"]["videoId"] for i in r.get("items", [])]
            token = r.get("nextPageToken")
            if not token:
                break
        ids = ids[:max_videos]
        videos = []
        for k in range(0, len(ids), 50):
            videos += yt.videos().list(part="snippet,contentDetails,statistics,status",
                                       id=",".join(ids[k:k + 50])).execute().get("items", [])

        today = date.today()
        end = today.isoformat()
        start = (today - timedelta(days=days)).isoformat()
        per, engaged = _per_video(ya, created, end)
        tot = _query(ya, startDate=start, endDate=end,
                     metrics="views,estimatedMinutesWatched,subscribersGained,subscribersLost")
        traffic = _query(ya, startDate=start, endDate=end, metrics="views",
                         dimensions="insightTrafficSourceType", sort="-views")
    except StatsError:
        raise
    except HttpError as e:
        msg = str(e)
        if "accessNotConfigured" in msg or "has not been used" in msg or "disabled" in msg:
            raise StatsError("Turn on \"YouTube Analytics API\" in your Google Cloud project "
                             "(APIs & Services → Library), wait a minute, then try again.") from e
        if "insufficient" in msg.lower() or "403" in msg:
            raise StatsError("YouTube refused the request. Press Reconnect YouTube and allow statistics.") from e
        raise StatsError(f"YouTube API error: {msg[:300]}") from e

    now = datetime.now(timezone.utc)
    lines = [
        f"CHANNEL: {title} ({cid}) · subscribers {subs} · report {datetime.now().strftime('%Y-%m-%d %H:%M')}",
        "SOURCE: YouTube Analytics API (about 2 days behind Studio realtime; impressions/CTR are not in the API)",
    ]
    if tot:
        t = tot[0]
        lines.append(f"LAST {days} DAYS: views {_n(t.get('views'))} · watch {t.get('estimatedMinutesWatched', 0) / 60:.1f} h"
                     f" · subs +{int(t.get('subscribersGained', 0))} / -{int(t.get('subscribersLost', 0))}")
    if traffic:
        total = sum(r["views"] for r in traffic) or 1
        parts = [f"{TRAFFIC_NAMES.get(r['insightTrafficSourceType'], r['insightTrafficSourceType'].replace('_', ' ').title())}"
                 f" {100 * r['views'] / total:.0f}%"
                 for r in traffic[:6]]
        lines.append("TRAFFIC (views): " + " · ".join(parts))

    head = "type | published | age | length | title | views | " + ("engaged | " if engaged else "") + \
           "avg view | % viewed | likes | comments | subs | status"
    lines += ["", "VIDEOS (newest first, lifetime):", head]
    for v in videos:
        sn, st, cd, stt = v["snippet"], v.get("statistics", {}), v["contentDetails"], v.get("status", {})
        secs = _secs(cd.get("duration", ""))
        pub = datetime.fromisoformat(sn["publishedAt"].replace("Z", "+00:00"))
        a = per.get(v["id"], {})
        row = [
            "S" if secs and secs <= SHORT_MAX_SECONDS else "L",
            pub.strftime("%Y-%m-%d"), _age(pub, now), _mmss(secs), sn["title"][:70],
            _n(st.get("viewCount")),
        ]
        if engaged:
            row.append(_n(a.get("engagedViews")) if a else "-")
        row += [
            _mmss(a.get("averageViewDuration")) if a else "-",

"""YouTube upload through the official Data API (OAuth, your own Google Cloud project).

Setup once:
  1. console.cloud.google.com -> new project -> enable "YouTube Data API v3"
  2. OAuth consent screen: External, add yourself as a test user
  3. Credentials -> Create OAuth client ID -> type "Desktop app" -> download JSON
  4. Save it as ~/.beatframe/client_secret.json, then press "Connect YouTube" in the app
  5. For the Stats page also enable "YouTube Analytics API" in the same project

Note: until the Google Cloud project passes YouTube's API audit, every video uploaded
through the API is locked to Private. The app still uploads (handy for drafts), and the
"manual upload" panel always works.
"""

from __future__ import annotations

import json
import os
from datetime import datetime, timezone
from pathlib import Path
from typing import Callable

CONFIG_DIR = Path(os.environ.get("BEATFRAME_HOME", Path.home() / ".beatframe"))
CLIENT_SECRET = CONFIG_DIR / "client_secret.json"
TOKEN = CONFIG_DIR / "youtube_token.json"
SCOPES = [
    "https://www.googleapis.com/auth/youtube.upload",
    "https://www.googleapis.com/auth/youtube.force-ssl",   # captions
    "https://www.googleapis.com/auth/youtube.readonly",    # channel name
    "https://www.googleapis.com/auth/yt-analytics.readonly",  # Stats page
]

os.environ.setdefault("OAUTHLIB_INSECURE_TRANSPORT", "1")  # loopback http://127.0.0.1 only
os.environ.setdefault("OAUTHLIB_RELAX_TOKEN_SCOPE", "1")

_pending: dict[str, object] = {}   # state -> Flow (keeps the PKCE verifier between redirects)


def is_configured() -> bool:
    return CLIENT_SECRET.exists()


def _creds():
    from google.auth.transport.requests import Request
    from google.oauth2.credentials import Credentials

    if not TOKEN.exists():
        return None
    # use the scopes saved with the token (an older login may not have every scope in SCOPES;
    # asking for more on refresh would fail and break uploads until the next Connect)
    creds = Credentials.from_authorized_user_file(str(TOKEN))
    if creds and creds.expired and creds.refresh_token:
        creds.refresh(Request())
        TOKEN.write_text(creds.to_json(), encoding="utf-8")
    return creds if creds and creds.valid else None


def is_connected() -> bool:
    try:
        return _creds() is not None
    except Exception:  # noqa: BLE001
        return False


def channel_name() -> str:
    try:
        from googleapiclient.discovery import build

        yt = build("youtube", "v3", credentials=_creds(), cache_discovery=False)
        items = yt.channels().list(part="snippet", mine=True).execute().get("items", [])
        return items[0]["snippet"]["title"] if items else ""
    except Exception:  # noqa: BLE001
        return ""


def auth_url(redirect_uri: str) -> str:
    from google_auth_oauthlib.flow import Flow

    flow = Flow.from_client_secrets_file(str(CLIENT_SECRET), scopes=SCOPES, redirect_uri=redirect_uri)
    url, state = flow.authorization_url(access_type="offline", prompt="consent", include_granted_scopes="true")
    _pending[state] = flow
    return url


def finish(state: str, full_url: str) -> None:
    flow = _pending.pop(state, None)
    if flow is None:
        raise RuntimeError("login session expired, press Connect again")
    flow.fetch_token(authorization_response=full_url)
    CONFIG_DIR.mkdir(parents=True, exist_ok=True)
    TOKEN.write_text(flow.credentials.to_json(), encoding="utf-8")


def disconnect() -> None:
    TOKEN.unlink(missing_ok=True)


def upload(
    video: Path,
    meta: dict,
    log: Callable[[str], None],
    progress: Callable[[float], None],
    captions: Path | None = None,
    thumbnail: Path | None = None,
) -> dict:
    from googleapiclient.discovery import build
    from googleapiclient.http import MediaFileUpload

    import socket
    import time

    socket.setdefaulttimeout(300)          # slow uploads: wait up to 5 minutes per chunk instead of 60 s
    creds = _creds()
    if not creds:
        raise RuntimeError("YouTube is not connected")
    yt = build("youtube", "v3", credentials=creds, cache_discovery=False)

    status = {
        "privacyStatus": meta.get("privacy", "private"),
        "selfDeclaredMadeForKids": False,
        "containsSyntheticMedia": bool(meta.get("synthetic", False)),
    }
    if meta.get("publish_at"):
        # publishAt only works for private videos; YouTube makes them public at that time
        status["privacyStatus"] = "private"
        status["publishAt"] = meta["publish_at"]

    body = {
        "snippet": {
            "title": meta["title"][:100],
            "description": meta.get("description", "")[:5000],
            "tags": meta.get("tags", [])[:30],
            "categoryId": meta.get("category", "27"),   # 27 = Education
            "defaultLanguage": "en",
            "defaultAudioLanguage": "en",
        },
        "status": status,
    }
    media = MediaFileUpload(str(video), mimetype="video/mp4", chunksize=1024 * 1024, resumable=True)
    req = yt.videos().insert(part="snippet,status", body=body, media_body=media)
    log(f"uploading {video.name} ({video.stat().st_size / 1e6:.1f} MB)")
    resp = None
    tries = 0
    while resp is None:
        try:
            st, resp = req.next_chunk()
            tries = 0
            if st:
                progress(st.progress() * 0.9)
        except Exception as e:  # noqa: BLE001 - slow / unstable internet: wait and resume the same upload
            from googleapiclient.errors import HttpError

            if isinstance(e, HttpError) and e.resp.status not in (500, 502, 503, 504):
                raise
            tries += 1
            if tries > 8:
                raise RuntimeError(f"upload stopped after {tries - 1} retries: {e}. Check the internet and press Upload again.") from e
            wait = min(60, 3 * 2 ** (tries - 1))
            log(f"connection problem ({type(e).__name__}), retry {tries}/8 in {wait}s - the upload continues where it stopped")
            time.sleep(wait)
    vid = resp["id"]
    log(f"uploaded: https://youtu.be/{vid}")
    result = {"id": vid, "url": f"https://youtu.be/{vid}", "studio": f"https://studio.youtube.com/video/{vid}/edit",
              "privacy": resp.get("status", {}).get("privacyStatus", ""), "warnings": []}

    if captions and captions.exists():
        try:
            yt.captions().insert(
                part="snippet",
                body={"snippet": {"videoId": vid, "language": "en", "name": "English", "isDraft": False}},
                media_body=MediaFileUpload(str(captions), mimetype="application/octet-stream"),
            ).execute()
            log("subtitles added")
        except Exception as e:  # noqa: BLE001
            result["warnings"].append(f"subtitles: {e}")
            log(f"subtitles skipped: {e}")
    if thumbnail and thumbnail.exists():
        try:
            yt.thumbnails().set(videoId=vid, media_body=MediaFileUpload(str(thumbnail))).execute()
            log("thumbnail set")
        except Exception as e:  # noqa: BLE001
            msg = "custom thumbnails need a phone-verified channel" if "forbidden" in str(e).lower() else str(e)
            result["warnings"].append(f"thumbnail: {msg}")
            log(f"thumbnail skipped: {msg}")
    progress(1.0)
    return result


def to_rfc3339(local_value: str, tz_offset_minutes: int) -> str:
    """'2026-10-05T18:30' from <input type=datetime-local> + browser offset -> UTC RFC3339."""
    dt = datetime.fromisoformat(local_value)
    from datetime import timedelta

    utc = dt + timedelta(minutes=tz_offset_minutes)
    return utc.replace(tzinfo=timezone.utc).isoformat().replace("+00:00", "Z")

        kind = "installed" if "installed" in data else ("web" if "web" in data else "?")
        return {"kind": kind, "project": (data.get(kind) or {}).get("project_id", "")}
    except Exception:  # noqa: BLE001
        return {"kind": "invalid"}

"""Projects live on disk exactly like the CLI uses them: projects/<slug>/<slug>.yaml."""

from __future__ import annotations

import json
import re
import time
from dataclasses import dataclass
from pathlib import Path
from typing import Any, get_args, get_origin, Literal

from pydantic import ValidationError

from beatframe.formats import FORMATS, get_format

def slugify(text: str) -> str:
    s = re.sub(r"[^a-z0-9]+", "-", text.lower()).strip("-")
    return s[:48] or "video"


def friendly_error(e: Exception) -> str:
    if isinstance(e, ValidationError):
        lines = []
        for err in e.errors():
            loc = ".".join(str(x) for x in err["loc"])
            lines.append(f"{loc}: {err['msg']}")
        return "\n".join(lines)
    return str(e)


@dataclass
class ProjectInfo:
    slug: str
    title: str
    beats: int
    modified: float
    has_final: bool
    has_preview: bool
    duration: float | None
    fmt: str = "long"
    thumb: str | None = None          # path under the projects root, for /files/...
    broken: bool = False

    @property
    def status(self) -> str:
        return "completed" if self.has_final else "draft"


def _video_info(f: Path) -> dict:
    """Size, time and render manifest (format, resolution, length) of an output video."""
    info = {"name": f.name, "mtime": int(f.stat().st_mtime), "size": f.stat().st_size}
    meta = f.with_suffix(".json")
    if meta.exists():
        try:
            info.update(json.loads(meta.read_text(encoding="utf-8")))
        except ValueError:
            pass
    return info


class Store:
    def __init__(self, root: Path):
        self.root = root
        self.root.mkdir(parents=True, exist_ok=True)

    # ---- paths -----------------------------------------------------------
    def folder(self, slug: str) -> Path:
        if not re.fullmatch(r"[a-z0-9-]+", slug):
            raise KeyError(slug)
        return self.root / slug

    def file(self, slug: str) -> Path:
        return self.folder(slug) / f"{slug}.yaml"

    def output(self, slug: str) -> Path:
        return self.folder(slug) / "output"

    # ---- read ------------------------------------------------------------
    def list(self) -> list[ProjectInfo]:
        items = []
        for f in sorted(self.root.glob("*/*.yaml")):
            if f.stem != f.parent.name:
                continue
            broken, fmt = False, "long"
            try:
                p = parse_project(f.read_text(encoding="utf-8"))
                title, beats, fmt = p.title, len(p.beats), p.video.format
            except Exception:  # noqa: BLE001
                title, beats, broken = f"{f.stem} (script has errors)", 0, True
            out = f.parent / "output"
            vids = list(out.glob("*.mp4")) if out.exists() else []
            finals = [v for v in vids if v.stem in ("final", "final_short")]
            dur = None
            if finals:
                dur = _video_info(max(finals, key=lambda v: v.stat().st_mtime)).get("duration")
            items.append(ProjectInfo(
                slug=f.stem, title=title, beats=beats,
                modified=max([f.stat().st_mtime] + [x.stat().st_mtime for x in vids]),
                has_final=bool(finals),
                has_preview=any(v.stem.startswith("preview") for v in vids),
                duration=dur, fmt=fmt, thumb=self.cover(f.stem), broken=broken,
            ))
        return sorted(items, key=lambda i: -i.modified)

    def exists(self, slug: str) -> bool:
        return self.file(slug).exists()

    def raw(self, slug: str) -> str:
        return self.file(slug).read_text(encoding="utf-8")

    def load(self, slug: str) -> Project:
        return parse_project(self.raw(slug))

    # ---- write -----------------------------------------------------------
    def check_text(self, text: str) -> tuple[Project | None, str]:
        """Parse + validate pasted YAML. Returns (project, error_message)."""
        try:
            p = parse_project(text)
        except Exception as e:  # noqa: BLE001
            return None, friendly_error(e)
        problems = validate(p)
        if problems:
            return None, "\n".join(problems)
        return p, ""

    def create(self, text: str) -> tuple[str | None, str]:
        p, err = self.check_text(text)
        if not p:
            return None, err
        base = slugify(p.title)
        slug, n = base, 2
        while self.exists(slug):
            slug, n = f"{base}-{n}", n + 1
        self.folder(slug).mkdir(parents=True, exist_ok=True)
        self.file(slug).write_text(text.strip() + "\n", encoding="utf-8")
        return slug, ""

    def save_text(self, slug: str, text: str) -> str:
        p, err = self.check_text(text)
        if not p:
            return err
        self.file(slug).write_text(text.strip() + "\n", encoding="utf-8")
        return ""

    def save(self, slug: str, project: Project) -> None:
        self.file(slug).write_text(dump_project(project), encoding="utf-8")

    def apply_options(self, slug: str, title: str = "", fmt: str = "") -> None:
        """Set the title and/or video format. The file is only rewritten if something changes,
        so a pasted script keeps its comments when the defaults are used."""
        project = self.load(slug)
        changed = False
        if title.strip() and title.strip() != project.title:
            project.title, changed = title.strip(), True
        if fmt and get_format(fmt).name != project.video.format:
            project.video, changed = project.video.with_format(fmt), True
        if changed:
            self.save(slug, project)

    def outputs(self, slug: str, fmt: str = "long") -> dict[str, Any]:
        """Rendered files of one format: final / preview / beat_preview videos, subtitles,
        chapters and thumbnail candidates. `other` lists videos of the other formats."""
        out = self.output(slug)
        spec = get_format(fmt)
        files: dict[str, Any] = {"fmt": spec.name, "spec": spec.to_dict()}
        for kind in ("final", "preview", "beat_preview"):
            f = out / output_name(kind, spec.name)
            files[kind] = _video_info(f) if f.exists() else None
        for name in ("subtitles.srt", "chapters.txt"):
            f = out / name
            files[name] = {"name": name, "mtime": int(f.stat().st_mtime), "size": f.stat().st_size} if f.exists() else None
        tdir = out / ("thumbs" + spec.suffix)
        files["thumb_dir"] = tdir.name
        files["thumbs"] = sorted(p.name for p in tdir.glob("*.png")) if tdir.exists() else []
        files["other"] = [
            {"fmt": other.name, "label": other.label, "aspect": other.aspect, "kind": kind}
            for other in FORMATS.values() if other.name != spec.name
            for kind in ("final", "preview") if (out / output_name(kind, other.name)).exists()
        ]
        return files

    def cover(self, slug: str) -> str | None:
        """An image to show for the project in lists (relative to the projects root)."""
        out = self.output(slug)
        if not out.exists():
            return None
        for cand in [out / "thumbnail.jpg", out / "thumbnail.png",
                     *sorted((out / "thumbs").glob("*.png")), *sorted((out / "thumbs_short").glob("*.png"))]:
            if cand.exists():
                return str(cand.relative_to(self.root))
        return None

    def chapters(self, slug: str) -> str:
        f = self.output(slug) / "chapters.txt"
        return f.read_text(encoding="utf-8").strip() if f.exists() else ""

def template_fields(scene: str, values: dict) -> list[dict]:
    """Describe a template's params so the page can draw a matching form."""
    cls = get_template(scene)
    fields = []
    for name, info in cls.Params.model_fields.items():
        ann = info.annotation
        current = values.get(name, info.default)
        f = {"name": name, "value": current, "default": info.default}
        if ann is bool:
            f["kind"] = "bool"
        elif ann in (int, float):
            f["kind"] = "number"
            f["step"] = "1" if ann is int else "any"
        elif get_origin(ann) is Literal:
            f["kind"] = "select"
            f["options"] = list(get_args(ann))
        elif get_origin(ann) is list:
            f["kind"] = "list"
            f["value"] = ", ".join(str(x) for x in (current or []))
        else:
            f["kind"] = "textarea" if len(str(current or "")) > 60 else "text"
        fields.append(f)
    return fields


def params_from_form(scene: str, form: dict) -> dict:
    """Turn submitted form fields (prefixed 'p.') back into a params dict."""
    cls = get_template(scene)
    out: dict = {}
    for name, info in cls.Params.model_fields.items():
        key = f"p.{name}"
        ann = info.annotation
        if ann is bool:
            val = form.get(key) in ("on", "true", "1")
        elif key not in form:
            continue
        else:
            raw = str(form[key]).strip()
            if ann is int:
                val = int(float(raw)) if raw else info.default
            elif ann is float:
                val = float(raw) if raw else info.default
            elif get_origin(ann) is list:
                val = [x.strip() for x in raw.split(",") if x.strip()]
            else:
                val = raw
        if val != info.default:
            out[name] = val
    return out


def template_catalog() -> list[dict]:
    get_template(next(iter(REGISTRY), "title_card"))  # make sure every template module is imported
    return [{"name": n, "description": REGISTRY[n].description,
             "short_native": REGISTRY[n].vertical_width <= 8.0,
             "fields": template_fields(n, {})} for n in sorted(REGISTRY)]


def new_beat(after: Beat | None = None) -> Beat:
    return Beat(text="New sentence for the narrator.", scene="statement",
                params={"text": "New sentence for the narrator."})


def now() -> float:
    return time.time()

def _ago(t: float) -> str:
    d = time.time() - t
    if d < 60:
        return "just now"
    if d < 3600:
        return f"{int(d // 60)} min ago"
    if d < 86400:
        return f"{int(d // 3600)} h ago"
    if d < 7 * 86400:
        n = int(d // 86400)
        return f"{n} day{'s' if n > 1 else ''} ago"
    return time.strftime("%d %b", time.localtime(t))


def _size(n: int | None) -> str:
    if not n:
        return ""
    return f"{n / 1e6:.1f} MB" if n >= 1e6 else f"{max(1, round(n / 1e3))} KB"


def _secs(s: float | None) -> str:
    if not s:
        return ""
    s = int(round(s))
    return f"{s // 60}:{s % 60:02d}"

def _parse_beats(beats: Optional[str]) -> list[int] | None:
    if not beats:
        return None
    out: list[int] = []
    for part in beats.split(","):
        if "-" in part:
            a, b = part.split("-")
            out += list(range(int(a), int(b) + 1))
        else:
            out.append(int(part))
    return out

"""The whole run: voice -> timing -> clips -> final video and extras."""

from __future__ import annotations

import json
import math
import shutil
from datetime import datetime
from dataclasses import dataclass, field
from pathlib import Path
from typing import Callable

from beatframe import assemble
from beatframe.render import ClipJob, render_all
from beatframe.schema import Project
from beatframe.templates import get_template
from beatframe.tts import auto_pad, make_voice

PREVIEW_FPS = 15

Progress = Callable[[dict], None]


def output_name(kind: str, video_format: str | None = None) -> str:
    """Output file for a render kind ("preview", "final", "beat_preview") in a format.

    Long keeps the original names (final.mp4); short gets a suffix (final_short.mp4).
    """
    from beatframe.formats import get_format

    return f"{kind}{get_format(video_format).suffix}.mp4"


@dataclass
class RunResult:
    out_dir: Path
    video: Path
    durations: list[float] = field(default_factory=list)

    @property
    def total(self) -> float:
        return sum(self.durations)


def validate(project: Project) -> list[str]:
    """Return a list of human-readable problems (empty = fine)."""
    problems = []
    for i, b in enumerate(project.beats, 1):
        try:
            cls = get_template(b.scene)
            cls.Params.model_validate(b.params)
        except Exception as e:  # noqa: BLE001
            problems.append(f"beat {i}: {e}")
    return problems


def run(
    project: Project,
    project_file: Path,
    preview: bool = False,
    only: list[int] | None = None,
    workers: int | None = None,
    log: Callable[[str], None] = print,
    out_name: str | None = None,
    video_format: str | None = None,
    progress: Progress | None = None,
) -> RunResult:
    """Render a project.

    video_format  "long" / "short"; overrides project.video.format for this run.
    out_name      output kind ("preview", "final", "beat_preview"); the format suffix is added.
    progress      receives {"stage": "voice"|"render"|"assemble"|"extras"|"done", "done": n,
                  "total": n, "beat": i, "template": name} as the run advances.
    """
    root = project_file.parent
    build = root / "build"
    out_dir = root / "output"
    out_dir.mkdir(parents=True, exist_ok=True)

    def report(stage: str, **kw) -> None:
        if progress:
            progress({"stage": stage, **kw})

    problems = validate(project)
    if problems:
        raise ValueError("project has problems:\n  " + "\n  ".join(problems))

    video = project.video.with_format(video_format) if video_format else project.video
    fmt = video.spec
    w, h = video.size(preview)
    fps = PREVIEW_FPS if preview else video.fps
    log(f"format: {fmt.name} ({fmt.aspect}, {w}x{h} @ {fps} fps)")

    # 1. voice + exact beat length (rounded up to whole frames)
    voices, durations = [], []
    n_beats = len(project.beats)
    for i, b in enumerate(project.beats, 1):
        report("voice", done=i - 1, total=n_beats, beat=i)
        wav, secs = make_voice(i, b, project.voice, build / "audio", n_beats)
        nxt = project.beats[i] if i < n_beats else None
        d = max(b.min_duration, secs + auto_pad(i, b, nxt))
        d = math.ceil(d * fps) / fps
        voices.append(wav)
        durations.append(d)
    report("voice", done=n_beats, total=n_beats)
    log(f"voice ready: {len(voices)} beats, {sum(durations):.1f} s total")

    # 2. clips
    jobs = [
        ClipJob(i, b.scene, b.params, durations[i - 1], w, h, fps)
        for i, b in enumerate(project.beats, 1)
        if not only or i in only
    ]
    clips_dir = build / (("clips_preview" if preview else "clips") + fmt.suffix)
    finished = {"n": 0}

    def started(job: ClipJob) -> None:
        report("render", done=finished["n"], total=len(jobs), beat=job.index, template=job.template)

    def done(job: ClipJob, path: Path, cached: bool) -> None:
        finished["n"] += 1
        report("render", done=finished["n"], total=len(jobs), beat=job.index, template=job.template, cached=cached)
        log(f"  beat {job.index:03d} {job.template:<20} {job.duration:5.1f}s {'(cached)' if cached else 'rendered'}")

    report("render", done=0, total=len(jobs))
    clips = render_all(jobs, clips_dir, workers=workers, on_done=done, on_start=started)

    # 3. assemble (only beats that were rendered, in order)
    report("assemble")
    order = sorted(clips)
    sel_durs = [durations[i - 1] for i in order]
    voice_track = build / (("voice_preview" if preview else "voice") + fmt.suffix + ".wav")
    assemble.build_audio([voices[i - 1] for i in order], sel_durs, voice_track)
    audio = build / (("mix_preview" if preview else "mix") + fmt.suffix + ".wav")
    from beatframe import audio as audio_mod, brand
    starts_sel = [sum(sel_durs[:k]) for k in range(len(sel_durs))]
    audio_mod.mix(voice_track, audio, length=sum(sel_durs), starts=starts_sel,
                  chapters=[bool(project.beats[i - 1].chapter) for i in order], settings=project.audio,
                  project_dir=root, default_mood=getattr(brand, "MUSIC_MOOD", "mystery"), build_dir=build)

    kind = (out_name or ("preview" if preview else "final")).removesuffix(".mp4")
    out_video = out_dir / output_name(kind, fmt.name)
    assemble.build_video([clips[i] for i in order], audio, out_video)

    if not preview and not only:
        report("extras")
        texts = [b.text for b in project.beats]
        assemble.write_srt(texts, durations, out_dir / "subtitles.srt")
        assemble.write_chapters([b.chapter for b in project.beats], durations, out_dir / "chapters.txt")
        starts = [sum(durations[:i]) for i in range(len(durations))]
        assemble.extract_thumbs(out_video, starts, durations, out_dir / ("thumbs" + fmt.suffix))

    manifest = {
        "video": out_video.name, "format": fmt.name, "aspect": fmt.aspect, "width": w, "height": h,
        "fps": fps, "preview": preview, "beats": order, "duration": round(sum(sel_durs), 2),
        "rendered_at": datetime.now().isoformat(timespec="seconds"),
    }
    (out_dir / (out_video.stem + ".json")).write_text(json.dumps(manifest, indent=2), encoding="utf-8")
    report("done", video=out_video.name)
    log(f"done: {out_video}")
    return RunResult(out_dir, out_video, sel_durs)


def clean(project_file: Path) -> None:
    shutil.rmtree(project_file.parent / "build", ignore_errors=True)

"""Voice for each beat. Returns the audio file and its length in seconds.

Providers:
  edge   - free Microsoft Edge neural voices (needs internet). With style "auto" (default) every
           beat gets its own small change of speed and pitch from what the sentence is (hook,

  kokoro - Kokoro-82M, a free open-source AI voice that runs on this computer (no internet after the

           install once with ovoz_ornat.sh.
  files  - your own recordings: <files_dir>/001.mp3, 002.wav, ... one per beat
  silent - no voice, length estimated from word count (for quick layout tests)
"""

from __future__ import annotations

import asyncio
import hashlib
import re
import shutil
import subprocess
import wave
from pathlib import Path

from beatframe.schema import Beat, Voice

AUDIO_EXTS = (".wav", ".mp3", ".m4a", ".ogg", ".flac")


def probe_duration(path: Path) -> float:
    path = Path(path)
    if path.suffix.lower() == ".wav":
        try:
            with wave.open(str(path), "rb") as w:
                return w.getnframes() / float(w.getframerate())
        except wave.Error:
            pass
    out = subprocess.run(
        ["ffprobe", "-v", "error", "-show_entries", "format=duration", "-of", "csv=p=0", str(path)],
        capture_output=True, text=True, check=True,
    ).stdout.strip()
    return float(out)


def _to_wav(src: Path, dst: Path) -> None:
    subprocess.run(
        ["ffmpeg", "-v", "error", "-y", "-i", str(src), "-ac", "1", "-ar", "48000", str(dst)],
        check=True,
    )


def _silence(dst: Path, seconds: float) -> None:
    subprocess.run(
        ["ffmpeg", "-v", "error", "-y", "-f", "lavfi", "-i", "anullsrc=r=48000:cl=mono",
         "-t", f"{seconds:.3f}", str(dst)],
        check=True,
    )


# ---- expressive delivery ----------------------------------------------------------------
def _pct(s: str) -> int:
    m = re.match(r"\s*([+-]?\d+)\s*%", s or "")
    return int(m.group(1)) if m else 0


def _hz(s: str) -> int:
    m = re.match(r"\s*([+-]?\d+)\s*Hz", s or "", re.I)
    return int(m.group(1)) if m else 0


def delivery(index: int, beat: Beat, voice: Voice, total: int = 0) -> tuple[str, str]:
    """Speed and pitch for one beat (edge-tts strings like "+4%", "-2Hz").

    style "flat" keeps the project's rate/pitch on every beat (the old behaviour).
    style "auto" reads the sentence like a storyteller would:
      * the hook (beat 1) and exclamations come a little faster and brighter,
      * very short lines ("And then, nothing.") are slowed down so they land,
      * a new chapter starts slower and lower,
      * questions slow down slightly,
      * long explanations speed up a touch so they don't drag,
      * plus a small, repeatable variation per beat so no two beats sound identical.
    """
    rate, pitch = _pct(voice.rate), _hz(voice.pitch)
    if voice.style == "flat":
        return f"{rate:+d}%", f"{pitch:+d}Hz"
    text = beat.text.strip()
    words = len(text.split())
    r, p = 0, 0
    if index == 1:
        r, p = r + 5, p + 2
    if beat.chapter and index > 1:
        r, p = r - 5, p - 2
    if text.endswith("!"):
        r, p = r + 5, p + 3
    elif text.endswith("?"):
        r, p = r - 3, p + 1
    if words <= 6:
        r, p = r - 8, p - 2
    elif words >= 26:
        r += 4
    # repeatable jitter: same beat text -> same delivery (keeps the voice cache valid)
    h = int(hashlib.md5(f"{index}|{text}".encode()).hexdigest()[:6], 16)
    r += (h % 7) - 3            # -3..+3 %
    p += ((h >> 4) % 5) - 2     # -2..+2 Hz
    k = voice.expressiveness
    rate_out = int(round(rate + r * k))
    pitch_out = int(round(pitch + p * k))
    return f"{max(-30, min(30, rate_out)):+d}%", f"{max(-20, min(20, pitch_out)):+d}Hz"


def auto_pad(index: int, beat: Beat, next_beat: Beat | None) -> float:
    """Breathing room after a beat: longer after questions, punchlines and before a new chapter."""
    if beat.pad != Beat.model_fields["pad"].default:
        return beat.pad                       # set by hand in the script: keep it
    text = beat.text.strip()
    pad = 0.3
    if text.endswith("?"):
        pad = 0.6
    elif len(text.split()) <= 6 or text.endswith(("...", "…")):
        pad = 0.55
    if next_beat is not None and next_beat.chapter:
        pad += 0.45
    return pad


async def _edge(text: str, voice: Voice, rate: str, pitch: str, dst: Path) -> None:
    import edge_tts

    await edge_tts.Communicate(text, voice.name, rate=rate, pitch=pitch).save(str(dst))


# ---- kokoro (local AI voice) ------------------------------------------------------------
_KOKORO: dict = {}
KOKORO_ENV = Path.home() / ".kokoro" / "bin" / "python"      # separate Python 3.12 made by ovoz_ornat.sh

KOKORO_HELP = ("Kokoro is not installed. Run once in a terminal:\n"
               "  bash ~/Desktop/\"YouTube content\"/beatframe2.0/ovoz_ornat.sh")


def _kokoro_worker():
    """Start (once) the Kokoro worker in its own Python and return the process."""
    proc = _KOKORO.get("proc")
    if proc is not None and proc.poll() is None:
        return proc
    if not KOKORO_ENV.exists():
        raise RuntimeError(KOKORO_HELP)
    worker = Path(__file__).with_name("kokoro_worker.py")
    proc = subprocess.Popen([str(KOKORO_ENV), str(worker)], stdin=subprocess.PIPE, stdout=subprocess.PIPE,
                            text=True, bufsize=1)
    first = proc.stdout.readline().strip()
    if first != "ready":
        raise RuntimeError(f"Kokoro did not start: {first or 'no answer'}\n{KOKORO_HELP}")
    _KOKORO["proc"] = proc
    return proc


def _kokoro(text: str, voice: Voice, speed: float, dst: Path) -> None:
    import json

    proc = _kokoro_worker()
    proc.stdin.write(json.dumps({"text": text, "voice": voice.name, "speed": speed, "out": str(dst)}) + "\n")
    proc.stdin.flush()
    answer = proc.stdout.readline().strip()
    if answer != "ok":
        raise RuntimeError(f"Kokoro failed on: {text[:60]}… ({answer or 'worker stopped'})")


# Older, flatter edge voices are swapped for their more natural "Multilingual" versions.
UPGRADE = {
    "en-US-ChristopherNeural": "en-US-BrianMultilingualNeural",
    "en-US-AndrewNeural": "en-US-AndrewMultilingualNeural",
    "en-US-BrianNeural": "en-US-BrianMultilingualNeural",
    "en-US-AvaNeural": "en-US-AvaMultilingualNeural",
    "en-US-EmmaNeural": "en-US-EmmaMultilingualNeural",
}


def effective_voice(voice: Voice) -> Voice:
    """The voice actually used: ovoz.txt in the app folder can switch every project at once
    (e.g. "kokoro am_michael" or "edge en-US-AndrewMultilingualNeural"); old flat edge voices are upgraded."""
    from beatframe import brand

    f = Path(getattr(brand, "APP_DIR", Path(__file__).resolve().parent.parent)) / "ovoz.txt"
    try:
        words = f.read_text(encoding="utf-8").split()
    except OSError:
        words = []
    if words and words[0] in ("edge", "kokoro") and voice.provider in ("edge", "kokoro"):
        voice = voice.model_copy(update={"provider": words[0], "name": words[1] if len(words) > 1 else
                                         ("am_michael" if words[0] == "kokoro" else voice.name)})
    if voice.provider == "edge" and voice.upgrade and voice.name in UPGRADE:
        voice = voice.model_copy(update={"name": UPGRADE[voice.name]})
    return voice


def make_voice(index: int, beat: Beat, voice: Voice, audio_dir: Path, total: int = 0) -> tuple[Path, float]:
    """Create (or reuse) the voice clip for one beat. index is 1-based."""
    audio_dir.mkdir(parents=True, exist_ok=True)
    voice = effective_voice(voice)
    wav = audio_dir / f"{index:03d}.wav"
    stamp = audio_dir / f"{index:03d}.txt"
    rate, pitch = delivery(index, beat, voice, total)
    key = f"{voice.provider}|{voice.name}|{rate}|{pitch}|{beat.text}"

    if wav.exists() and stamp.exists() and stamp.read_text(encoding="utf-8") == key:
        return wav, probe_duration(wav)

    if voice.provider == "silent":
        words = len(beat.text.split())
        _silence(wav, max(beat.min_duration, words / voice.words_per_second))
    elif voice.provider == "files":
        if not voice.files_dir:
            raise ValueError("voice.provider=files needs voice.files_dir")
        folder = Path(voice.files_dir)
        found = [folder / f"{index:03d}{ext}" for ext in AUDIO_EXTS if (folder / f"{index:03d}{ext}").exists()]
        if not found:
            raise FileNotFoundError(f"no audio for beat {index} in {folder} (expected {index:03d}.mp3 or .wav)")
        _to_wav(found[0], wav)
    elif voice.provider == "edge":
        mp3 = audio_dir / f"{index:03d}.mp3"
        asyncio.run(_edge(beat.text, voice, rate, pitch, mp3))
        _to_wav(mp3, wav)
        mp3.unlink(missing_ok=True)
    elif voice.provider == "kokoro":
        raw = audio_dir / f"{index:03d}_k.wav"
        speed = max(0.6, min(1.5, 1.0 + _pct(rate) / 100))
        _kokoro(beat.text, voice, speed, raw)
        _to_wav(raw, wav)
        raw.unlink(missing_ok=True)
    else:  # pragma: no cover
        raise ValueError(f"unknown voice provider {voice.provider}")

    stamp.write_text(key, encoding="utf-8")
    return wav, probe_duration(wav)


def has_ffmpeg() -> bool:
    return shutil.which("ffmpeg") is not None and shutil.which("ffprobe") is not None


=== FAYL: ./beatframe/audio.py ===
"""Music and sound effects under the narration.

Nothing is downloaded: the background music is generated here (soft chords, bass, a few plucked
notes, reverb) in one of several moods, so it is royalty-free and never triggers a Content ID claim.
A project can use its own track instead (audio.music: "music.mp3" in the project folder).

Mixing: the music is "ducked" (pushed down) automatically while the narrator speaks and comes up
in the pauses; a soft whoosh marks each scene change and a low hit marks every new chapter.
"""

from __future__ import annotations

import subprocess
import wave
from pathlib import Path

import numpy as np

SR = 48000

# mood -> (root Hz, chords as semitones from the root, seconds per chord, pluck scale, percussion bpm or 0)
MOODS = {
    "mystery": (110.0, [[0, 3, 7, 10], [-4, 0, 3, 7], [-7, -4, 0, 3], [-5, -1, 2, 7]], 8.0, [0, 3, 5, 7, 10, 12], 0),
    "wonder":  (146.8, [[0, 4, 7, 11], [-3, 0, 4, 7], [-7, -3, 0, 4], [-5, -1, 2, 7]], 8.0, [0, 2, 4, 7, 9, 12], 0),
    "epic":    (73.4,  [[0, 3, 7, 12], [-4, 0, 3, 8], [-9, -5, 0, 3], [-2, 2, 5, 10]], 4.0, [0, 3, 7, 12], 84),
    "tense":   (82.4,  [[0, 3, 7, 10], [0, 3, 6, 10], [1, 5, 8, 13], [0, 3, 7, 10]], 6.0, [0, 1, 3, 7], 100),
    "calm":    (130.8, [[0, 4, 7, 11], [-3, 0, 4, 9], [-7, -3, 0, 4], [-5, -1, 2, 7]], 8.0, [0, 2, 4, 7, 9], 0),
}


def _note(freq: float, dur: float, harmonics: int = 6, detune: float = 0.004) -> np.ndarray:
    """A soft, string-like tone: a few detuned voices with gently falling harmonics."""
    t = np.arange(int(dur * SR)) / SR
    out = np.zeros_like(t)
    for d in (-detune, 0.0, detune):
        f = freq * (1 + d)
        for h in range(1, harmonics + 1):
            out += np.sin(2 * np.pi * f * h * t + h * 0.7) / (h ** 1.6)
    return out / 3.0


def _envelope(n: int, attack: float, release: float) -> np.ndarray:
    a, r = int(attack * SR), int(release * SR)
    env = np.ones(n)
    env[:a] = np.linspace(0, 1, a) ** 2
    env[n - r:] *= np.linspace(1, 0, r) ** 1.5
    return env


def _reverb(x: np.ndarray, seconds: float = 2.8, wet: float = 0.35, seed: int = 3) -> np.ndarray:
    from scipy.signal import oaconvolve

    rng = np.random.default_rng(seed)
    n = int(seconds * SR)
    ir = rng.standard_normal(n) * np.exp(-np.linspace(0, 7, n))
    ir[0] = 0
    ir /= np.sqrt(np.sum(ir ** 2))
    tail = oaconvolve(x, ir)[: len(x)]
    return x * (1 - wet) + tail * wet


def _kick(dur: float = 0.6) -> np.ndarray:
    t = np.arange(int(dur * SR)) / SR
    f = 45 + 80 * np.exp(-t * 18)
    phase = 2 * np.pi * np.cumsum(f) / SR
    return np.sin(phase) * np.exp(-t * 7)


def music_loop(mood: str, seed: int = 1) -> np.ndarray:
    """One seamless loop (4 chords) of generated music, mono float32 at 48 kHz."""
    root, chords, chord_s, scale, bpm = MOODS.get(mood, MOODS["mystery"])
    rng = np.random.default_rng(seed)
    loop_n = int(chord_s * len(chords) * SR)
    # render three loops and keep the middle one, so the reverb tail wraps around seamlessly
    total = np.zeros(loop_n * 3)
    for rep in range(3):
        for ci, chord in enumerate(chords):
            start = rep * loop_n + int(ci * chord_s * SR)
            dur = chord_s + 1.5
            pad = sum(_note(root * 2 ** ((s + 12) / 12), dur, 5) for s in chord) / len(chord)
            pad *= _envelope(len(pad), min(1.8, chord_s * 0.3), 1.6) * 0.55
            bass = _note(root * 2 ** ((chord[0] % 12 - 12 if chord[0] > 0 else chord[0]) / 12), dur, 3) * 0.5
            bass *= _envelope(len(bass), 0.4, 1.4)
            seg = pad + bass
            end = min(len(total), start + len(seg))
            total[start:end] += seg[: end - start]
            # a few plucked notes, quiet, in the scale
            for _ in range(rng.integers(1, 4)):
                pos = start + int(rng.uniform(0.5, chord_s - 0.5) * SR)
                f = root * 4 * 2 ** (rng.choice(scale) / 12)
                n = int(1.6 * SR)
                t = np.arange(n) / SR
                pl = (np.sin(2 * np.pi * f * t) + 0.3 * np.sin(4 * np.pi * f * t)) * np.exp(-t * 3.2) * 0.22
                for k, g in ((0, 1.0), (int(0.37 * SR), 0.45), (int(0.74 * SR), 0.2)):   # simple echo
                    a = pos + k
                    b = min(len(total), a + n)
                    if a < len(total):
                        total[a:b] += pl[: b - a] * g
        if bpm:
            step = 60 / bpm
            beats = int(chord_s * len(chords) / step)
            for k in range(beats):
                if k % 4 in (0, 3) or (bpm >= 100 and k % 2 == 0):
                    a = rep * loop_n + int(k * step * SR)
                    kk = _kick() * (0.8 if k % 4 == 0 else 0.45)
                    b = min(len(total), a + len(kk))
                    total[a:b] += kk[: b - a]
    total = _reverb(total)
    loop = total[loop_n: 2 * loop_n]
    loop /= max(1e-6, np.max(np.abs(loop)))
    return (loop * 0.8).astype(np.float32)


def _whoosh(rng) -> np.ndarray:
    n = int(0.55 * SR)
    noise = rng.standard_normal(n)
    k = 24
    smooth = np.convolve(noise, np.ones(k) / k, mode="same")          # take the hiss off
    env = np.concatenate([np.linspace(0, 1, int(n * 0.55)) ** 2, np.linspace(1, 0, n - int(n * 0.55)) ** 1.5])
    return smooth * env * 1.6


def _hit() -> np.ndarray:
    n = int(1.6 * SR)
    t = np.arange(n) / SR
    f = 38 + 40 * np.exp(-t * 6)
    body = np.sin(2 * np.pi * np.cumsum(f) / SR) * np.exp(-t * 2.6)
    return body * 0.9


def sfx_track(starts: list[float], chapters: list[bool], length: float, seed: int = 5) -> np.ndarray:
    """Whoosh just before each scene change, a low hit on every chapter start (not the first beat)."""
    rng = np.random.default_rng(seed)
    out = np.zeros(int(length * SR) + SR, dtype=np.float32)
    for i, (t0, chap) in enumerate(zip(starts, chapters)):
        if i == 0:
            continue
        w = _whoosh(rng) * 0.35
        a = max(0, int((t0 - 0.35) * SR))
        out[a:a + len(w)] += w[: len(out) - a]
        if chap:
            h = _hit() * 0.6
            a = int(t0 * SR)
            out[a:a + len(h)] += h[: len(out) - a]
    return out[: int(length * SR)]


def write_wav(path: Path, x: np.ndarray) -> None:
    x = np.clip(x, -1, 1)
    with wave.open(str(path), "wb") as w:
        w.setnchannels(1)
        w.setsampwidth(2)
        w.setframerate(SR)
        w.writeframes((x * 32767).astype("<i2").tobytes())


def mix(voice: Path, out: Path, *, length: float, starts: list[float], chapters: list[bool],
        settings, project_dir: Path, default_mood: str = "mystery", build_dir: Path | None = None) -> None:
    """voice.wav + (ducked) music + sfx -> out.wav. With music none and sfx off, just copies the voice."""
    build_dir = build_dir or out.parent
    inputs = ["-i", str(voice)]
    chains = ["[0:a]aformat=sample_rates=48000:channel_layouts=stereo,asplit=2[v][key]"]
    mixes = ["[v]"]
    music_src = None
    if settings.music not in ("none", "off", ""):
        if settings.music == "auto":
            mood = default_mood if settings.mood == "auto" else settings.mood
            music_src = build_dir / f"music_{mood}.wav"
            if not music_src.exists():
                write_wav(music_src, music_loop(mood))
        else:
            music_src = (project_dir / settings.music)
            if not music_src.exists():
                raise FileNotFoundError(f"music file not found: {music_src} (put it in the project folder)")
    if music_src is not None:
        gain = max(0.0, settings.music_volume) * 0.55
        inputs += ["-stream_loop", "-1", "-i", str(music_src)]
        chains.append(f"[1:a]aformat=sample_rates=48000:channel_layouts=stereo,volume={gain:.3f},"
                      f"atrim=0:{length:.3f},afade=t=in:d=1.5,afade=t=out:st={max(0, length - 3):.3f}:d=3[mus]")
        chains.append("[mus][key]sidechaincompress=threshold=0.05:ratio=3:attack=80:release=800:makeup=1[duck]")
        mixes.append("[duck]")
    else:
        chains[0] = "[0:a]aformat=sample_rates=48000:channel_layouts=stereo[v]"
    if settings.sfx:
        sfx = build_dir / "sfx.wav"
        write_wav(sfx, sfx_track(starts, chapters, length) * max(0.0, settings.sfx_volume))
        idx = len([x for x in inputs if x == "-i"])
        inputs += ["-i", str(sfx)]
        chains.append(f"[{idx}:a]aformat=sample_rates=48000:channel_layouts=stereo[fx]")
        mixes.append("[fx]")
    if len(mixes) == 1:
        subprocess.run(["ffmpeg", "-v", "error", "-y", "-i", str(voice), "-ac", "2", str(out)], check=True)
        return
    graph = ";".join(chains) + ";" + "".join(mixes) + f"amix=inputs={len(mixes)}:normalize=0:duration=first[out]"
    subprocess.run(["ffmpeg", "-v", "error", "-y", *inputs, "-filter_complex", graph, "-map", "[out]",
                    "-t", f"{length:.3f}", str(out)], check=True)

"""Render one Manim clip per beat, with caching and parallel workers."""

from __future__ import annotations

import hashlib
import inspect
import json
import os
import shutil
import subprocess
import sys
import tempfile
from concurrent.futures import ThreadPoolExecutor, as_completed
from dataclasses import dataclass
from pathlib import Path
from typing import Callable

from beatframe.formats import frame_size
from beatframe.templates import base as base_mod
from beatframe.templates import get_template


@dataclass
class ClipJob:
    index: int            # 1-based beat number
    template: str
    params: dict
    duration: float
    width: int
    height: int
    fps: int


def _source_hash(template: str) -> str:
    cls = get_template(template)
    mod_src = inspect.getsource(sys.modules[cls.__module__])
    src = mod_src + inspect.getsource(base_mod)
    if "templates.kit" in mod_src:          # bright templates share the kit: its edits re-render them
        from beatframe.templates import kit
        src += inspect.getsource(kit)
    return hashlib.sha1(src.encode()).hexdigest()[:10]


def clip_key(job: ClipJob) -> str:
    payload = json.dumps(
        [job.template, job.params, round(job.duration, 2), job.width, job.height, job.fps,
         _source_hash(job.template)],
        sort_keys=True,
    )
    return hashlib.sha1(payload.encode()).hexdigest()[:12]


RUNNER = '''\
import json
from manim import config
from beatframe.templates.base import BeatScene

config.frame_width, config.frame_height = {frame_width!r}, {frame_height!r}

class Beat(BeatScene):
    template_name = {template!r}
    params = json.loads({params!r})
    beat_duration = {duration}
    seed = {seed}
'''


def render_clip(job: ClipJob, clips_dir: Path) -> Path:
    clips_dir.mkdir(parents=True, exist_ok=True)
    key = clip_key(job)
    out = clips_dir / f"{job.index:03d}_{key}.mp4"
    if out.exists():
        return out
    for old in clips_dir.glob(f"{job.index:03d}_*.mp4"):
        old.unlink()

    fw, fh = frame_size(job.width, job.height, get_template(job.template).vertical_width)
    with tempfile.TemporaryDirectory(prefix="beatframe_") as tmp:
        tmp = Path(tmp)
        runner = tmp / f"beat_{job.index:03d}.py"
        runner.write_text(
            RUNNER.format(template=job.template, params=json.dumps(job.params),
                          duration=job.duration, seed=job.index * 13 + 7,
                          frame_width=fw, frame_height=fh),
            encoding="utf-8",
        )
        cmd = [
            sys.executable, "-m", "manim", "render", str(runner), "Beat",
            "-r", f"{job.width},{job.height}", "--fps", str(job.fps),
            "--media_dir", str(tmp / "media"), "-o", "clip",
            "--disable_caching", "--progress_bar", "none", "-v", "WARNING",
        ]
        res = subprocess.run(cmd, capture_output=True, text=True)
        if res.returncode != 0:
            raise RuntimeError(f"beat {job.index} ({job.template}) failed:\n{res.stderr[-3000:]}")
        found = list((tmp / "media").rglob("clip.mp4"))
        if not found:
            raise RuntimeError(f"beat {job.index}: manim produced no video")
        shutil.move(str(found[0]), out)
    return out


def _run_one(job: ClipJob, clips_dir: Path, on_start: Callable[[ClipJob], None] | None) -> Path:
    if on_start:
        on_start(job)
    return render_clip(job, clips_dir)


def render_all(
    jobs: list[ClipJob],
    clips_dir: Path,
    workers: int | None = None,
    on_done: Callable[[ClipJob, Path, bool], None] | None = None,
    on_start: Callable[[ClipJob], None] | None = None,
) -> dict[int, Path]:
    workers = workers or max(1, (os.cpu_count() or 2) // 2)
    results: dict[int, Path] = {}
    with ThreadPoolExecutor(max_workers=workers) as pool:
        futs = {}
        for job in jobs:
            cached = (clips_dir / f"{job.index:03d}_{clip_key(job)}.mp4").exists()
            futs[pool.submit(_run_one, job, clips_dir, on_start)] = (job, cached)
        for fut in as_completed(futs):
            job, cached = futs[fut]
            results[job.index] = fut.result()
            if on_done:
                on_done(job, results[job.index], cached)

=== FAYL: ./beatframe/formats.py ===
"""Video formats: the single place that knows what "short" and "long" mean.

Everything else asks this module for sizes, so there are no scattered 9:16 checks.

  long  -> 16:9, 1920x1080  (YouTube, documentaries)  - the original Beatframe look
  short -> 9:16, 1080x1920  (Shorts, Reels, TikTok)

Manim coordinates: long frames are 14.2 x 8 units. Short frames are 8 x 14.2 for templates
that lay themselves out responsively; templates drawn for 16:9 declare how much of their
width must stay visible (Template.vertical_width) and get a wider portrait view.
"""

from __future__ import annotations

from dataclasses import dataclass
from typing import Literal

FormatName = Literal["long", "short"]
DEFAULT_FORMAT: FormatName = "long"
SHORT_SIDE_UNITS = 8.0


@dataclass(frozen=True)
class VideoFormat:
    name: FormatName
    label: str
    aspect: str
    width: int
    height: int
    preview_width: int
    preview_height: int
    description: str

    @property
    def vertical(self) -> bool:
        return self.height > self.width

    @property
    def suffix(self) -> str:
        """Added to cache folders and output names. Long keeps the original names."""
        return "" if self.name == "long" else f"_{self.name}"

    def size(self, preview: bool = False) -> tuple[int, int]:
        return (self.preview_width, self.preview_height) if preview else (self.width, self.height)

    def to_dict(self) -> dict:
        return {
            "name": self.name, "label": self.label, "aspect": self.aspect,
            "width": self.width, "height": self.height, "description": self.description,
        }


FORMATS: dict[str, VideoFormat] = {
    "long": VideoFormat("long", "Long", "16:9", 1920, 1080, 854, 480,
                        "Landscape video for YouTube and documentary content"),
    "short": VideoFormat("short", "Short", "9:16", 1080, 1920, 480, 854,
                         "Vertical video for Shorts, Reels and TikTok"),
}


def get_format(name: str | None) -> VideoFormat:
    key = (name or DEFAULT_FORMAT).lower()
    if key not in FORMATS:
        raise ValueError(f"unknown video format '{name}'. Use: {', '.join(FORMATS)}")
    return FORMATS[key]


def frame_size(pixel_width: int, pixel_height: int, vertical_width: float = SHORT_SIDE_UNITS) -> tuple[float, float]:
    """Manim frame (width, height) in scene units for a pixel size.

    Landscape: the short side is 8 units (Manim's default 14.2 x 8 frame). Sizes within 1% of
    16:9 (like the 854x480 preview) snap to exactly 16:9, so long renders are identical to
    the original Beatframe.

    Portrait: `vertical_width` units fit across the frame. 8 (default) is the native 8 x 14.2
    frame that responsive templates lay out for; a template drawn for 16:9 can ask for a
    wider view (up to 14.2) so its composition stays inside the frame.
    """
    ratio = max(pixel_width, pixel_height) / min(pixel_width, pixel_height)
    if abs(ratio - 16 / 9) < 0.01 * 16 / 9:
        ratio = 16 / 9
    if pixel_width >= pixel_height:
        return SHORT_SIDE_UNITS * ratio, SHORT_SIDE_UNITS
    return vertical_width, vertical_width * ratio

            scene.play(frame.animate(rate_func=linear).scale(1.06), run_time=rest)

"""A pressure-gated ion channel (Piezo2): a push bends the membrane, the gate opens,
ions rush in and the nerve fires."""

import numpy as np
from manim import (
    DOWN, LEFT, RIGHT, UP, Arrow, Circle, Dot, FadeIn, Line, RoundedRectangle, Text, ValueTracker,
    VGroup, VMobject, Create, linear, rate_functions, smooth,
)

from beatframe import brand
from beatframe.templates.base import Template, glow

MEM_Y = 0.4          # membrane centre line
GAP = 0.22           # half-thickness of the bilayer


def _bend(x, b):
    return -b * np.exp(-(x ** 2) / 3.0)


class IonChannel(Template):
    name = "ion_channel"
    description = "Membrane with a pressure-gated channel; push -> gate opens -> ions in -> spike"

    class Params(Template.Params):
        channel_label: str = "Piezo2"
        top_label: str = "outside"
        bottom_label: str = "inside the nerve"
        caption: str = "pressure pulls the gate open"
        show_spike: bool = True

    def build(self, scene, p, duration):
        bend = ValueTracker(0.0)
        opn = ValueTracker(0.0)

        # lipid heads: two rows of small circles, leaving a hole for the channel
        xs = [x for x in np.arange(-7.4, 7.5, 0.34) if abs(x) > 1.15]
        heads = VGroup()
        for row in (1, -1):
            for x in xs:
                c = Circle(radius=0.11).set_stroke(brand.PAPER, 1.5, 0.8).set_fill(brand.PAPER, 0.15)
                c.x0, c.row = x, row
                heads.add(c)

        def place_heads(g):
            b = bend.get_value()
            for c in g:
                c.move_to([c.x0, MEM_Y + c.row * GAP + _bend(c.x0, b), 0])
        place_heads(heads)
        heads.add_updater(place_heads)

        # the channel: two halves that slide apart as it opens
        def half(side):
            r = RoundedRectangle(width=0.55, height=1.0, corner_radius=0.2)
            r.set_stroke(brand.GLOW, 3).set_fill(brand.GLOW, 0.25)
            r.side = side
            return r
        halves = VGroup(half(-1), half(1))

        def place_halves(g):
            b, o = bend.get_value(), opn.get_value()
            for h in g:
                h.move_to([h.side * (0.3 + 0.36 * o), MEM_Y + _bend(0, b), 0])
        place_halves(halves)
        halves.add_updater(place_halves)

        # tethers ("springs") linking the channel to the membrane - Piezo's blades

"""Template base class, the shared scene, and the template registry.

A template is a class with:
  * name            - the value used in `scene:` in the project YAML
  * Params          - a pydantic model; it validates YAML params (and later drives the web form)
  * build(scene, p, duration) - draws the animation into `scene`, using about `duration` seconds

The runtime pads every beat to exactly its voice length, so a template only has to
spread its animations over `duration`; it never has to be exact.
"""

from __future__ import annotations

import random
from typing import ClassVar

import numpy as np
from manim import (
    Dot,
    MovingCameraScene,
    VGroup,
    config,
)
from pydantic import BaseModel

from beatframe import brand

REGISTRY: dict[str, type["Template"]] = {}


def glow(radius: float, color: str, layers: int = 6, strength: float = 0.18) -> VGroup:
    """A soft light: a solid core with fading halos around it."""
    from manim import Circle

    halo = VGroup(*[
        Circle(radius=radius * (1 + 0.55 * k)).set_stroke(width=0).set_fill(color, strength * (1 - k / layers))
        for k in range(1, layers + 1)
    ])
    core = Circle(radius=radius).set_stroke(width=0).set_fill(color, 1)
    return VGroup(halo, core)


def soft_glow(radius: float, color: str, layers: int = 8, strength: float = 0.07) -> VGroup:
    """A glow with no hard core: stacked transparent discs, brightest in the middle."""
    from manim import Circle

    return VGroup(*[
        Circle(radius=radius * k / layers).set_stroke(width=0).set_fill(color, strength)
        for k in range(layers, 0, -1)
    ])


# ---- layout helpers: templates use these instead of fixed numbers --------------
# Long (16:9) frames are 14.2 x 8 units. In short (9:16) mode a responsive template gets an
# 8 x 14.2 frame; a template drawn for 16:9 gets a portrait frame `vertical_width` units wide.
LONG_FRAME_WIDTH = 8.0 * 16 / 9


def frame_w() -> float:
    return config.frame_width


def frame_h() -> float:
    return config.frame_height


def width_ratio() -> float:
    """Frame width relative to the 16:9 frame: 1.0 in long mode, 0.56 for a responsive short."""
    return config.frame_width / LONG_FRAME_WIDTH


def fit(mob, max_width: float | None = None, max_height: float | None = None):
    """Shrink (never grow) a mobject so it fits inside the given size."""
    if max_width and mob.width > max_width:
        mob.scale_to_fit_width(max_width)
    if max_height and mob.height > max_height:
        mob.scale_to_fit_height(max_height)
    return mob


def keep_inside_x(mob, margin: float = 0.3) -> bool:
    """Slide a mobject left/right so it stays inside the frame. Returns False if it is too wide."""
    half = config.frame_width / 2 - margin
    if mob.width > 2 * half:
        return False
    x = mob.get_x()
    if x + mob.width / 2 > half:
        mob.set_x(half - mob.width / 2)
    elif x - mob.width / 2 < -half:
        mob.set_x(-half + mob.width / 2)
    return True


class Template:
    name: ClassVar[str] = ""
    description: ClassVar[str] = ""
    # Short (9:16) mode: how many units of width the frame shows. 8 = the template lays itself
    # out for a narrow frame (uses frame_w()/frame_h()/fit()). A template drawn for 16:9 keeps
    # the full 14.2 by default, or a narrower value if its important content fits in it.
    vertical_width: ClassVar[float] = LONG_FRAME_WIDTH
    # "night": dark brand background with drifting dust (the original look).
    # "bright": the template draws a colourful background itself (templates/kit.py).
    theme: ClassVar[str] = "night"

    class Params(BaseModel):
        pass

    def __init_subclass__(cls, **kw):
        super().__init_subclass__(**kw)
        if cls.name:
            REGISTRY[cls.name] = cls

    def build(self, scene: "BeatScene", p: BaseModel, duration: float) -> None:  # pragma: no cover
        raise NotImplementedError


def get_template(name: str) -> type[Template]:
    from beatframe import templates  # noqa: F401  (imports all template modules)

    if name not in REGISTRY:
        known = ", ".join(sorted(REGISTRY))
        raise KeyError(f"unknown scene '{name}'. Available: {known}")
    return REGISTRY[name]


class BeatScene(MovingCameraScene):
    """Scene used for every beat. Subclassed at render time with the beat's data."""

    template_name: str = ""
    params: dict = {}
    beat_duration: float = 3.0
    seed: int = 7

    def construct(self):
        brand.register_fonts()
        random.seed(self.seed)
        np.random.seed(self.seed)
        tpl_cls = get_template(self.template_name)
        if tpl_cls.theme == "bright":      # the template paints its own coloured background
            self.camera.background_color = "#FFF6E5"
        else:
            self.camera.background_color = brand.NIGHT
            self.add(self.dust())

        tpl = tpl_cls()
        p = tpl_cls.Params.model_validate(self.params)
        tpl.build(self, p, self.beat_duration)

        elapsed = getattr(self.renderer, "time", 0.0)
        if self.beat_duration - elapsed > 1 / config.frame_rate:
            self.wait(self.beat_duration - elapsed)

    # ---- shared helpers -------------------------------------------------
    def dust(self, n: int = 70) -> VGroup:
        """Slowly drifting specks of light, so no frame is ever fully still."""
        w, h = config.frame_width, config.frame_height
        specks = VGroup()
        for _ in range(n):
            d = Dot(
                point=[random.uniform(-w / 2, w / 2), random.uniform(-h / 2, h / 2), 0],
                radius=random.uniform(0.008, 0.028),
                color=brand.PAPER,
            ).set_opacity(random.uniform(0.08, 0.35))
            d.vel = np.array([random.uniform(-0.05, 0.05), random.uniform(0.02, 0.09), 0])
            specks.add(d)

        def drift(group, dt):
            for d in group:
                d.shift(d.vel * dt)
                x, y, _ = d.get_center()
                if y > h / 2 + 0.2:
                    d.move_to([x, -h / 2 - 0.2, 0])
                if abs(x) > w / 2 + 0.2:
                    d.move_to([-np.sign(x) * w / 2, y, 0])

        specks.add_updater(drift)
        specks.set_z_index(-10)
        return specks

"""A spoken line shown as large text, one key word lit in ember."""

import re

import numpy as np
from manim import BOLD, DOWN, UP, AnimationGroup, Circle, Dot, FadeIn, Text, VGroup, linear

from beatframe.templates.base import Template, frame_h, frame_w, soft_glow, width_ratio


def _motif(kind: str) -> VGroup | None:
    """Quiet moving background so text beats don't feel like slides."""
    if kind == "orb":
        g = soft_glow(3.4, brand.EMBER, layers=10, strength=0.03)
        g.t = 0.0
        g.k = 1.0

        def breathe(m, dt):
            m.t += dt
            k = 1 + 0.08 * np.sin(m.t * 1.3)
            m.scale(k / m.k)
            m.k = k
        g.add_updater(breathe)
        return g
    if kind == "rings":
        rings = VGroup(*[Circle(radius=1).set_stroke(brand.GLOW, 1.5, 0) for _ in range(5)])
        rings.t = 0.0

        def grow(m, dt):
            m.t += dt
            for i, c in enumerate(m):
                ph = (m.t * 0.22 + i / len(m)) % 1.0
                c.set(width=2 * (0.5 + 7.5 * ph)).move_to([0, 0, 0])
                c.set_stroke(opacity=0.22 * (1 - ph))
        rings.add_updater(grow)
        return rings
    if kind == "particles":
        rng = np.random.default_rng(11)
        half_w, half_h = 7.5 * width_ratio(), 4.5 * frame_h() / 8   # 7.5 x 4.5 in a 16:9 frame
        dots = VGroup()
        for _ in range(70):
            d = Dot([rng.uniform(-half_w, half_w), rng.uniform(-half_h, half_h), 0], radius=rng.uniform(0.015, 0.04),
                    color=brand.GLOW).set_opacity(rng.uniform(0.15, 0.5))
            d.v = rng.uniform(0.15, 0.45)
            dots.add(d)

        def drift(m, dt):
            for d in m:
                d.shift(UP * d.v * dt)
                if d.get_y() > half_h:
                    d.shift(DOWN * 2 * half_h)
        dots.add_updater(drift)
        return dots
    return None


class Statement(Template):
    name = "statement"
    description = "Large statement, words arrive one by one, one keyword glows"
    vertical_width = 8.0

    class Params(Template.Params):
        text: str = "Not your phone. Not this screen."
        highlight: str = ""        # word to light up (case-insensitive)
        max_chars: int = 20        # wrap width per line (16:9; narrower frames wrap shorter)
        motif: str = "none"        # none | orb | rings | particles  (quiet moving background)

    def build(self, scene, p, duration):
        # one sentence per block, then wrap each block
        sentences = [s for s in re.split(r"(?<=[.!?])\s+", p.text.strip()) if s]
        wrap = max(8, round(p.max_chars * width_ratio() ** 0.6))
        lines = []
        for s in sentences:
            lines += textwrap.wrap(s, wrap)

        rows, words_all = VGroup(), []
        for line in lines:
            row = VGroup()
            for w in line.split():
                hot = p.highlight and w.strip(".,!?;:'\"").lower() == p.highlight.lower()
                t = Text(w, font=brand.SERIF, weight=BOLD, color=brand.EMBER if hot else brand.PAPER).scale(1.15)
                row.add(t)
                words_all.append(t)
            row.arrange(buff=0.28, aligned_edge=DOWN)
            rows.add(row)
        rows.arrange(DOWN, buff=0.45)
        max_w, max_h = frame_w() * 0.872, frame_h() * 0.8   # 12.4 x 6.4 in a 16:9 frame
        if rows.width > max_w:
            rows.scale_to_fit_width(max_w)
        if rows.height > max_h:
            rows.scale_to_fit_height(max_h)

        bg = _motif(p.motif)
        if bg is not None:
            scene.add(bg)
        reveal = min(duration * 0.55, 0.22 * len(words_all) + 0.4)
        scene.play(
            AnimationGroup(*[FadeIn(w, shift=UP * 0.15) for w in words_all], lag_ratio=0.6),
            run_time=reveal,
        )
        rest = duration - getattr(scene.renderer, "time", 0)
        if rest > 0.2:
            scene.play(scene.camera.frame.animate.scale(0.95), run_time=rest, rate_func=linear)

def _brush():

    rate_functions, always_redraw,
)

from beatframe import brand
from beatframe.templates.base import Template, glow


def _wave(x0, x1, y, amp, color, phase_t, width=3, opacity=1.0):
    return FunctionGraph(lambda x: y + amp * np.sin(4.2 * x - phase_t) * np.exp(-((x - (x0 + x1) / 2) ** 2) / 2.2),
                         x_range=[x0, x1, 0.02]).set_stroke(color, width, opacity)


class Prediction(Template):
    name = "prediction"
    description = "Prediction wave minus touch wave: self-touch cancels out, someone else's does not"

    class Params(Template.Params):

        felt_label: str = "what your skin reports"
        result_label: str = "what you feel"
        verdict: str = ""                          # default: "almost nothing" / "the full tickle"

    def build(self, scene, p, duration):

        res_amp = ValueTracker(0.9)

        L0, L1, R0, R1 = -6.6, -1.4, 1.2, 6.4
        pred = always_redraw(lambda: _wave(L0, L1, 1.35, pred_amp.get_value(), brand.GLOW, t.get_value()))
        felt = always_redraw(lambda: _wave(L0, L1, -1.25, 0.9, brand.EMBER, t.get_value()))
        res = always_redraw(lambda: _wave(R0, R1, 0.05, res_amp.get_value(), brand.PAPER, t.get_value(), width=4))

        fl = Text(p.felt_label, font=brand.SANS, color=brand.EMBER).scale(0.4).move_to([(L0 + L1) / 2, -2.35, 0])
        rl = Text(p.result_label, font=brand.SANS, color=brand.PAPER).scale(0.42).move_to([(R0 + R1) / 2, 1.25, 0])

        vd.move_to([(R0 + R1) / 2, -1.25, 0])
        if not self_touch:
            pl_note = Text("(no prediction: it's not your move)", font=brand.SANS, color=brand.DIM).scale(0.32)
            pl_note.next_to(pl, DOWN, buff=0.12)
        else:
            pl_note = VGroup()

        def tick(m, dt):
            m.increment_value(dt * 4.0)
        t.add_updater(tick)
        scene.add(t)

        scene.play(FadeIn(guides), FadeIn(felt), FadeIn(fl), run_time=min(1.0, duration * 0.12))

        scene.play(FadeIn(vd, shift=UP * 0.1), run_time=0.5)
        rest = duration - scene.renderer.time
        if rest > 0.05:
            scene.wait(rest)

from beatframe.templates.base import Template
from beatframe.templates.kit import (
    ICONS, INK, PaletteName, Budget, caption_bar, card, drift_camera, fh, flat_bg, fw, icon, palette, parse_pair,

class ProcessCycle(Template):
    name = "process_cycle"
    description = "3-5 process steps ('icon|text') lighting up in order, optionally looping back"
    theme = "bright"
    vertical_width = 8.0

    class Params(Template.Params):
        title: str = ""
        steps: list[str] = ["sun|Daylight", "clock|Body clock", "moon|Melatonin", "zzz|Sleep"]
        loop: bool = True
        palette: PaletteName = "auto"

    def build(self, scene, p, duration):
        pal = palette(p.palette, scene.seed)
        flat_bg(scene, pal)
        W, H = fw(), fh()
        b = Budget(duration)
        steps = [parse_pair(x, "star") for x in p.steps[:5]] or [("star", "…")]
        n = len(steps)
        tall = vertical()
        colors = [pal["a"], pal["b"], pal["c"], pal["d"]]
        top_room = 1.6 if p.title else 0.4
        if tall:
            ch = min(1.5, (H - top_room - 1.2 - 0.6 * (n - 1)) / n)
            cw = W * 0.7
        else:
            cw = min(2.6, (W * 0.88 - 0.7 * (n - 1)) / n)
            ch = cw * 1.1
        nodes = VGroup()
        for i, (ic, text) in enumerate(steps):
            box = card(cw, ch)
            if tall:
                ico = icon(ic if ic in ICONS else "star", ch * 0.6, pal).move_to(box[-1].get_left() + RIGHT * ch * 0.55)
                t = wrap_label(text, 0.48, INK, chars=16, max_width=cw - ch * 1.2).next_to(ico, RIGHT, buff=0.35)
            else:
                ico = icon(ic if ic in ICONS else "star", cw * 0.42, pal).move_to(box[-1].get_center() + UP * ch * 0.14)
                t = wrap_label(text, 0.38, INK, chars=12, max_width=cw * 0.86).next_to(ico, DOWN, buff=0.25)
            nodes.add(VGroup(box, ico, t))
        nodes.arrange(DOWN if tall else RIGHT, buff=0.6 if tall else 0.7).move_to([0, -top_room / 2 + 0.2, 0])
        arrows = VGroup(*[Arrow(nodes[i].get_bottom() if tall else nodes[i].get_right(),
                                nodes[i + 1].get_top() if tall else nodes[i + 1].get_left(), buff=0.08, stroke_width=7,
                                max_tip_length_to_length_ratio=0.45).set_color(INK) for i in range(n - 1)])
        if p.title:
            scene.play(FadeIn(caption_bar(p.title, pal), shift=UP * 0.2), run_time=b.t(0.08, 0.5))
        each = b.t(0.62 / n, 0.7)
        for i in range(n):
            anims = [FadeIn(nodes[i], shift=(DOWN if tall else LEFT) * -0.3, scale=0.9)]
            if i:
                anims.append(GrowArrow(arrows[i - 1]))
            scene.play(*anims, run_time=each)
            scene.play(nodes[i][0][-1].animate.set_stroke(colors[i % 4], 8), run_time=min(0.2, each / 2))
        if p.loop and n > 2:
            if tall:
                start, end = nodes[-1].get_left() + LEFT * 0.1, nodes[0].get_left() + LEFT * 0.1
                back = CurvedArrow(start, end, angle=-1.2, stroke_width=6).set_color(pal["a"])
            else:
                start, end = nodes[-1].get_bottom() + DOWN * 0.1, nodes[0].get_bottom() + DOWN * 0.1
                back = CurvedArrow(start, end, angle=-0.9, stroke_width=6).set_color(pal["a"])
            scene.play(FadeIn(back), run_time=b.t(0.08, 0.5))
        drift_camera(scene, duration)

"""Animated bar chart: bars grow, values count, one bar can be highlighted.
Vertical bars in 16:9, horizontal bars in 9:16 (easier to read on a phone)."""

from __future__ import annotations

from manim import DOWN, LEFT, RIGHT, UP, FadeIn, GrowFromEdge, Line, RoundedRectangle, VGroup

from beatframe.templates.base import Template
from beatframe.templates.kit import (
    INK, PaletteName, Budget, caption_bar, drift_camera, fh, flat_bg, fw, label, palette, vertical,
)


class BarChart(Template):
    name = "bar_chart"
    description = "Bars grow to their values (labels, values, unit); highlight one of them"
    theme = "bright"
    vertical_width = 8.0

    class Params(Template.Params):
        title: str = ""
        labels: list[str] = ["Babies", "Teens", "Adults"]
        values: list[float] = [16, 9, 7]
        unit: str = "h"
        highlight: int = 0            # 1-based bar to colour; 0 = all coloured
        palette: PaletteName = "auto"

    def build(self, scene, p, duration):
        pal = palette(p.palette, scene.seed)
        flat_bg(scene, pal)
        W, H = fw(), fh()
        b = Budget(duration)
        n = max(1, min(len(p.labels), len(p.values), 6))
        labels, values = p.labels[:n], [max(0.0, float(v)) for v in p.values[:n]]
        top = max(values) or 1
        colors = [pal["a"], pal["c"], pal["b"], pal["d"]]
        tall = vertical()
        if p.title:
            scene.play(FadeIn(caption_bar(p.title, pal), shift=UP * 0.2), run_time=b.t(0.08, 0.5))

        def fmt(v):
            return (f"{v:g}" if v != int(v) else f"{int(v)}") + p.unit

        bars = VGroup()
        if tall:
            area_w, gap = W * 0.52, 0.35
            bh = min(1.0, (H * 0.5 - gap * (n - 1)) / n)
            y0 = (n - 1) * (bh + gap) / 2 - 0.3
            x0 = -W * 0.18
            axis = Line([x0, y0 + bh, 0], [x0, y0 - (n - 1) * (bh + gap) - bh, 0]).set_stroke(INK, 5, 0.6)
            for i, (lab, v) in enumerate(zip(labels, values)):
                col = colors[i % 4] if not p.highlight or p.highlight == i + 1 else "#B8C0CC"
                w = max(0.08, area_w * v / top)
                bar = RoundedRectangle(width=w, height=bh, corner_radius=min(0.15, bh / 3)).set_stroke(width=0).set_fill(col, 1)
                bar.move_to([x0 + w / 2, y0 - i * (bh + gap), 0])
                name = label(lab, 0.38, INK, max_width=W * 0.28).next_to([x0, bar.get_y(), 0], LEFT, buff=0.2)
                val = label(fmt(v), 0.4, INK).next_to(bar, RIGHT, buff=0.15)
                bars.add(VGroup(bar, name, val))
        else:
            area_h, gap = H * 0.5, 0.5
            bw = min(1.6, (W * 0.7 - gap * (n - 1)) / n)
            base = -H * 0.28
            x_start = -((n - 1) * (bw + gap)) / 2
            axis = Line([x_start - bw, base, 0], [-x_start + bw, base, 0]).set_stroke(INK, 5, 0.6)
            for i, (lab, v) in enumerate(zip(labels, values)):
                col = colors[i % 4] if not p.highlight or p.highlight == i + 1 else "#B8C0CC"
                h = max(0.08, area_h * v / top)
                bar = RoundedRectangle(width=bw, height=h, corner_radius=min(0.15, bw / 4)).set_stroke(width=0).set_fill(col, 1)
                bar.move_to([x_start + i * (bw + gap), base + h / 2, 0])
                name = label(lab, 0.36, INK, max_width=bw + gap * 0.8).next_to([bar.get_x(), base, 0], DOWN, buff=0.25)
                val = label(fmt(v), 0.42, INK).next_to(bar, UP, buff=0.15)
                bars.add(VGroup(bar, name, val))
        scene.play(FadeIn(axis), *[FadeIn(g[1]) for g in bars], run_time=b.t(0.1, 0.5))
        edge = LEFT if tall else DOWN
        scene.play(*[GrowFromEdge(g[0], edge) for g in bars], run_time=b.t(0.3, 1.3))
        scene.play(*[FadeIn(g[2], shift=(RIGHT if tall else UP) * 0.15) for g in bars], run_time=b.t(0.1, 0.45))
        if p.highlight and 1 <= p.highlight <= n:
            g = bars[p.highlight - 1]
            scene.play(g.animate.scale(1.06), run_time=b.t(0.06, 0.3))
        drift_camera(scene, duration)

"""Events on a timeline ('1904|Olympic marathon'): horizontal in 16:9, vertical in 9:16."""

from __future__ import annotations

import numpy as np
from manim import DOWN, LEFT, RIGHT, UP, Circle, Create, FadeIn, GrowFromCenter, Line, VGroup, linear

from beatframe.templates.base import Template
from beatframe.templates.kit import (
    INK, WHITE, PaletteName, Budget, caption_bar, card, drift_camera, fh, flat_bg, fw, label, palette, parse_pair,

)


class Timeline(Template):
    name = "timeline"
    description = "2-5 dated events ('year|what happened') appearing along a timeline"
    theme = "bright"
    vertical_width = 8.0

    class Params(Template.Params):
        title: str = ""
        events: list[str] = ["300,000 BC|First humans", "10,000 BC|First farms", "1879|Light bulb"]
        palette: PaletteName = "auto"

    def build(self, scene, p, duration):
        pal = palette(p.palette, scene.seed)
        flat_bg(scene, pal)
        W, H = fw(), fh()
        b = Budget(duration)
        ev = [parse_pair(x, "") for x in p.events[:5]] or [("", "…")]
        n = len(ev)
        tall = vertical()
        top_room = 1.6 if p.title else 0.3
        colors = [pal["a"], pal["b"], pal["c"], pal["d"]]
        if p.title:
            scene.play(FadeIn(caption_bar(p.title, pal), shift=UP * 0.2), run_time=b.t(0.08, 0.5))
        if tall:
            y0, y1 = H / 2 - top_room - 1.0, -H / 2 + 1.2
            x = -W * 0.3
            pts = [np.array([x, y0 + (y1 - y0) * (i / max(n - 1, 1)), 0]) for i in range(n)]
            axis = Line([x, y0 + 0.4, 0], [x, y1 - 0.4, 0])
        else:
            x0, x1 = -W * 0.38, W * 0.38
            y = -0.2 - top_room / 3
            pts = [np.array([x0 + (x1 - x0) * (i / max(n - 1, 1)), y, 0]) for i in range(n)]
            axis = Line([x0 - 0.5, y, 0], [x1 + 0.5, y, 0])
        axis.set_stroke(INK, 7, 0.75)
        scene.play(Create(axis), run_time=b.t(0.1, 0.6), rate_func=linear)
        each = b.t(0.62 / n, 0.7)
        for i, ((when, what), pt) in enumerate(zip(ev, pts)):
            col = colors[i % 4]
            dot = VGroup(Circle(radius=0.26).set_stroke(WHITE, 6).set_fill(col, 1)).move_to(pt)
            year = label(when, 0.5 if tall else 0.46, col)
            text = wrap_label(what, 0.42 if tall else 0.36, INK, chars=18 if tall else 14, max_width=W * (0.5 if tall else 0.2))
            if tall:
                year.next_to(dot, RIGHT, buff=0.4).shift(UP * 0.2)
                text.next_to(year, DOWN, buff=0.12).align_to(year, LEFT)
            else:
                side = UP if i % 2 == 0 else DOWN
                year.next_to(dot, side, buff=0.35)
                text.next_to(year, side, buff=0.15)
            scene.play(GrowFromCenter(dot), FadeIn(year, shift=-0.2 * (RIGHT if tall else (UP if i % 2 == 0 else DOWN))),
                       FadeIn(text), run_time=each)
        drift_camera(scene, duration)


=== FAYL: ./beatframe/templates/scale_zoom.py ===
"""'Powers of ten' dive: the camera keeps falling into smaller and smaller worlds.

Each level is drawn at normal size. While the camera dives into the level's target
point, the next level fades in, already shrunk into that point. When the dive ends,
everything is rescaled back (invisibly), so the numbers never get tiny; on screen it
is one continuous zoom.
"""

from __future__ import annotations

import numpy as np
from manim import (
    DOWN, LEFT, ORIGIN, RIGHT, UP, Arc, Circle, Dot, FadeIn, FadeOut, Line, ParametricFunction,
    Rectangle, RoundedRectangle, Text, VGroup, config, linear, rate_functions,
)

from beatframe import brand
from beatframe.templates.base import Template, glow, keep_inside_x

ZOOM = 0.12  # each dive shrinks the view to this fraction


SURFACE_Y = -2.2


def _surface(y: float = SURFACE_Y) -> VGroup:
    top = Line([-9, y, 0], [9, y, 0]).set_stroke(brand.GLOW, 3)
    depth = max(3.0, config.frame_height / 2 + y + 0.5)   # reaches the bottom edge of tall frames
    body = Rectangle(width=18, height=depth).set_stroke(width=0).set_fill(brand.GLOW, 0.06)
    body.next_to(top, DOWN, buff=0)
    return VGroup(body, top)


def _label(text: str, pos, color=brand.DIM) -> Text:
    """A level label; in narrow frames it moves under the surface instead of off-screen."""
    lab = Text(text, font=brand.SANS, color=color).scale(0.42).move_to(pos)
    if config.frame_width / 2 - 0.3 < lab.get_x() + lab.width / 2:
        lab.move_to([0, SURFACE_Y - 1.6, 0])
    keep_inside_x(lab)
    return lab


def level_fingertip():
    finger = RoundedRectangle(width=3.0, height=7.0, corner_radius=1.45)
    finger.set_stroke(brand.PAPER, 3).set_fill(brand.DEEP, 1).move_to([0, 1.31, 0])
    ridges = VGroup(*[
        Arc(radius=0.45 + 0.17 * k, start_angle=np.pi * 1.12, angle=np.pi * 0.76)
        .set_stroke(brand.PAPER, 1.4, opacity=0.35)
        .move_to([0, -1.3 + 0.07 * k, 0])
        for k in range(7)
    ])
    g = VGroup(_surface(), finger, ridges, _label("your fingertip", [3.4, 0.4, 0]))
    return g, np.array([0.0, -2.2, 0]), "1 cm"


def level_skin():
    waves = VGroup()
    for k in range(5):
        y0 = -1.85 + 0.55 * k
        waves.add(
            ParametricFunction(lambda t, y0=y0: np.array([t, y0 + 0.26 * np.sin(2.2 * t + 1.57), 0]),
                               t_range=[-8.5, 8.5]).set_stroke(brand.PAPER, 2.5, opacity=0.9 - 0.15 * k)
        )
    g = VGroup(_surface(), waves, _label("fingerprint ridges", [3.8, 2.4, 0]))
    return g, np.array([0.0, -2.2, 0]), "1 mm"


def level_cells():
    rng = np.random.default_rng(3)
    cells = VGroup()
    for row in range(5):
        for col in range(-9, 10):
            r = 0.42 + rng.uniform(-0.05, 0.05)
            c = Circle(radius=r).set_stroke(brand.PAPER, 2, opacity=0.7).set_fill(brand.PAPER, 0.04)
            c.move_to([col * 0.9 + (0.45 if row % 2 else 0), -1.72 + row * 0.82, 0])
            cells.add(VGroup(c, Dot(c.get_center(), radius=0.08, color=brand.PAPER).set_opacity(0.5)))
    g = VGroup(_surface(), cells, _label("skin cells", [3.8, 2.6, 0]))
    return g, np.array([0.45, -2.2, 0]), "10 µm"


def _atom_row(color, y0, dy, xoff):
    atoms = VGroup()
    for row in range(3):
        for x in np.arange(-8.25, 8.3, 0.75):
            a = VGroup(glow(0.07, color, layers=4, strength=0.12),
                       Circle(radius=0.32).set_stroke(color, 1.5, 0.5))
            a.move_to([x + xoff, y0 + dy * row, 0])
            a.phase = np.random.uniform(0, 2 * np.pi)
            a.off = np.zeros(3)
            atoms.add(a)
    atoms.amp = 0.03
    atoms.t = 0.0

    def jiggle(group, dt):
        group.t += dt
        for a in group:
            new = group.amp * np.array([np.sin(9 * group.t + a.phase), np.cos(7 * group.t + a.phase), 0])
            a.shift(new - a.off)
            a.off = new

    atoms.add_updater(jiggle)
    return atoms


def level_atoms():
    top = _atom_row(brand.PAPER, 0.35, 0.7, 0.0)
    bottom = _atom_row(brand.GLOW, -0.75, -0.7, 0.375)
    g = VGroup(bottom, top,
               _label("your skin's atoms", [0, 2.55, 0], brand.PAPER),
               _label("the table's atoms", [0, -3.15, 0], brand.GLOW))
    g.jigglers = [top, bottom]
    return g, np.array([0.0, -0.2, 0]), "1 nm"


LEVELS = {
    "fingertip": level_fingertip,
    "skin": level_skin,
    "cells": level_cells,
    "atoms": level_atoms,
}


class ScaleZoom(Template):
    name = "scale_zoom"
    description = "Continuous dive through scales: fingertip -> skin -> cells -> atoms"
    vertical_width = 8.0

    class Params(Template.Params):
        levels: list[str] = ["fingertip", "skin", "cells", "atoms"]
        show_scale_bar: bool = True

    def build(self, scene, p, duration):
        frame = scene.camera.frame
        W, H = config.frame_width, config.frame_height
        levels = [LEVELS[name]() for name in p.levels]

        # scale bar glued to the screen corner, whatever the camera does
        state = {"label": levels[0][2]}

        def make_bar():
            line = Line(LEFT * 0.8, RIGHT * 0.8).set_stroke(brand.PAPER, 3)
            lab = Text(state["label"], font=brand.SANS, color=brand.PAPER).scale(0.4)
            bar = VGroup(line, lab.next_to(line, UP, buff=0.12))
            s = frame.width / W
            return bar.scale(s).move_to(frame.get_center() + np.array([-W / 2 + 1.5, -H / 2 + 0.8, 0]) * s)

        bar = make_bar()
        bar.add_updater(lambda m: m.become(make_bar()))

        cur, target, _ = levels[0]
        intro = min(0.8, duration * 0.12)
        scene.play(FadeIn(cur), FadeIn(bar) if p.show_scale_bar else FadeIn(VGroup()), run_time=intro)
        if not p.show_scale_bar:
            bar.clear_updaters()

        n = len(levels) - 1
        hold_end = min(1.5, duration * 0.2)
        seg = max(0.9, (duration - intro - hold_end) / max(n, 1))

        for i in range(n):
            nxt, nxt_target, nxt_label = levels[i + 1]
            # pre-shrink the next world into the point we are diving toward
            nxt.scale(ZOOM, about_point=ORIGIN).shift(target)
            for j in getattr(nxt, "jigglers", []):
                j.amp *= ZOOM

            def switch_label(_m, alpha, lbl=nxt_label):
                if alpha > 0.9:
                    state["label"] = lbl

            from manim import UpdateFromAlphaFunc

            scene.play(
                frame.animate(rate_func=rate_functions.ease_in_out_sine).scale(ZOOM).move_to(target),
                FadeIn(nxt, rate_func=rate_functions.squish_rate_func(rate_functions.smooth, 0.72, 0.98)),
                FadeOut(cur, rate_func=rate_functions.squish_rate_func(rate_functions.smooth, 0.82, 1.0)),
                UpdateFromAlphaFunc(VGroup(), switch_label),
                run_time=seg,
            )
            # invisible reset back to normal coordinates
            nxt.shift(-target).scale(1 / ZOOM, about_point=ORIGIN)
            for j in getattr(nxt, "jigglers", []):
                j.amp /= ZOOM
            frame.move_to(ORIGIN).set(width=W)
            cur, target = nxt, nxt_target

        rest = duration - getattr(scene.renderer, "time", 0)
        if rest > 0.2:
            scene.play(frame.animate.scale(0.92).move_to(target * 0.3), run_time=rest, rate_func=linear)

"""A touch signal racing from the fingertip up the arm and spine to the brain, with a stopwatch."""

import numpy as np
from manim import (
    DOWN, LEFT, RIGHT, UP, Circle, FadeIn, Line, MoveAlongPath, Text, ValueTracker, VGroup, VMobject,
    Create, linear, rate_functions, TracedPath,
)

from beatframe import brand
from beatframe.templates.base import Template, glow, soft_glow

HEAD = np.array([3.6, 2.15, 0])
NECK = np.array([3.6, 1.25, 0])
SHOULDER = np.array([2.7, 0.75, 0])
ELBOW = np.array([0.2, -0.35, 0])
WRIST = np.array([-3.0, -1.05, 0])
TIP = np.array([-4.9, -1.25, 0])


class NerveRace(Template):
    name = "nerve_race"
    description = "Signal travels fingertip -> arm -> spine -> brain with a millisecond counter"
    vertical_width = 12.4   # short mode: the part of the 16:9 drawing that stays in frame

    class Params(Template.Params):
        total_ms: int = 20
        speed_label: str = "up to ~70 m/s"
        caption: str = "fingertip to brain"

    def build(self, scene, p, duration):
        body = VGroup(
            Circle(radius=0.62).move_to(HEAD + UP * 0.15),
            Line(NECK, NECK + DOWN * 3.6),                         # spine
            VMobject().set_points_smoothly([NECK + DOWN * 0.35, SHOULDER, ELBOW, WRIST]),   # upper edge of arm
        ).set_stroke(brand.DIM, 2.2, 0.7)
        hand = VGroup(*[Line(WRIST, WRIST + np.array([-1.0 - 0.7 * (k == 1), 0.25 - 0.18 * k, 0]))
                        for k in range(4)]).set_stroke(brand.DIM, 2.2, 0.7)
        brain = soft_glow(1.1, brand.GLOW, layers=9, strength=0.08).move_to(HEAD + UP * 0.15)

        path = VMobject().set_points_smoothly([TIP, WRIST, ELBOW, SHOULDER, NECK + DOWN * 0.1])
        path.append_points(Line(NECK + DOWN * 0.1, HEAD + UP * 0.1).points)
        nerve = path.copy().set_stroke(brand.GLOW, 2, 0.35)

        labels = VGroup(
            Text("fingertip", font=brand.SANS, color=brand.DIM).scale(0.34).next_to(TIP, DOWN, buff=0.25),
            Text("spinal cord", font=brand.SANS, color=brand.DIM).scale(0.34).next_to(NECK + DOWN * 2.2, RIGHT, buff=0.2),
            Text("brain", font=brand.SANS, color=brand.DIM).scale(0.34).next_to(HEAD, RIGHT, buff=0.9),
        )
        ms = ValueTracker(0)
        timer = Text("0 ms", font=brand.SERIF, weight="BOLD", color=brand.PAPER).scale(1.0).move_to([-4.6, 2.5, 0])

        def upd_timer(m):
            m.become(Text(f"{int(round(ms.get_value()))} ms", font=brand.SERIF, weight="BOLD",
                          color=brand.PAPER).scale(1.0).move_to([-4.6, 2.5, 0]))
        timer.add_updater(upd_timer)
        speed = Text(p.speed_label, font=brand.SANS, color=brand.GLOW).scale(0.4).next_to(timer, DOWN, buff=0.2).align_to(timer, LEFT)
        cap = Text(p.caption, font=brand.SERIF, weight="BOLD", color=brand.PAPER).scale(0.6).move_to([-0.3, -3.2, 0])

        spark = glow(0.09, brand.EMBER, layers=5, strength=0.25).move_to(TIP)
        trail = TracedPath(spark.get_center, stroke_color=brand.EMBER, stroke_width=4, dissipating_time=0.35)

        scene.play(FadeIn(body), FadeIn(hand), FadeIn(nerve), FadeIn(labels), FadeIn(cap), run_time=min(1.0, duration * 0.14))
        scene.play(FadeIn(timer), FadeIn(speed), FadeIn(spark, scale=0.3), run_time=0.5)
        scene.add(trail)
        rest = duration - scene.renderer.time

import re

from manim import BOLD, DOWN, UP, FadeIn, Line, Text, ValueTracker, VGroup, always_redraw, linear, smooth

from beatframe import brand
from beatframe.templates.base import Template, fit, frame_w, glow


class SourceCard(Template):
    name = "source_card"
    description = "Counting number + caption + study citation"
    vertical_width = 8.0

    class Params(Template.Params):
        number: str = "13 nm"            # leading number counts up; the rest is the unit
        caption: str = "the smallest wrinkle a fingertip could feel"
        study: str = "Skedung et al., Scientific Reports (2013)"
        count: bool = True               # false: show the number as written (years, "#1"...)

    def build(self, scene, p, duration):
        m = re.match(r"\s*([\d.,]+)\s*(.*)", p.number)
        target = float(m.group(1).replace(",", "")) if m and p.count else None
        unit = m.group(2) if m and p.count else p.number
        decimals = len(m.group(1).split(".")[1]) if m and "." in m.group(1) else 0

        tracker = ValueTracker(0)

        def number_mob():
            val = tracker.get_value()
            txt = f"{val:,.{decimals}f}" if target is not None else ""
            full = f"{txt} {unit}".strip()
            num = Text(full, font=brand.SERIF, weight=BOLD, color=brand.GLOW).scale(2.0)
            return fit(num, max_width=frame_w() * 0.88).move_to(UP * 0.6)

        num = always_redraw(number_mob)
        rule = Line([-3.2, 0, 0], [3.2, 0, 0]).set_stroke(brand.DIM, 2).shift(DOWN * 0.75)
        cap = fit(Text(p.caption, font=brand.SANS, color=brand.PAPER).scale(0.5), max_width=frame_w() * 0.88)
        cap.next_to(rule, DOWN, buff=0.35)
        src = fit(Text(p.study, font=brand.SANS, color=brand.DIM).scale(0.36), max_width=frame_w() * 0.88)
        src.next_to(cap, DOWN, buff=0.3)
        light = glow(0.06, brand.EMBER).move_to(rule.get_start())

        scene.add(num)
        count = min(1.6, duration * 0.35)
        scene.play(
            tracker.animate.set_value(target or 0),
            rule.animate.set_stroke(brand.GLOW, 2),
            light.animate.move_to(rule.get_end()),
            run_time=count, rate_func=smooth,
        )
        scene.play(FadeIn(cap, shift=UP * 0.1), run_time=min(0.6, duration * 0.12))
        scene.play(FadeIn(src), run_time=min(0.5, duration * 0.1))
        num.clear_updaters()
        rest = duration - getattr(scene.renderer, "time", 0)
        if rest > 0.2:
            scene.play(
                scene.camera.frame.animate.scale(0.95),
                light.animate.move_to(rule.get_start()),
                run_time=rest, rate_func=linear,
            )

"""Why touch is never contact: two rows of atoms approach, their electron clouds push
back harder and harder, and the gap never closes."""

from __future__ import annotations

import numpy as np
from manim import (
    DOWN, UP, Arrow, BackgroundRectangle, Circle, DashedLine, FadeIn, Text, ValueTracker, VGroup, linear, rate_functions,
)

from beatframe import brand
from beatframe.templates.base import Template, frame_w, glow


def _atom(color):
    cloud = VGroup(*[
        Circle(radius=0.55 * (1 - k * 0.15)).set_stroke(width=0).set_fill(color, 0.05 + 0.03 * k)
        for k in range(5)
    ])
    ring = Circle(radius=0.55).set_stroke(color, 1.5, 0.45)
    core = glow(0.08, color, layers=3, strength=0.2)
    a = VGroup(cloud, ring, core)
    a.cloud, a.ring = cloud, ring
    return a


class ElectronRepulsion(Template):
    name = "electron_repulsion"
    description = "Two rows of atoms approach; electron clouds repel; the gap never closes"
    vertical_width = 8.0

    class Params(Template.Params):
        top_label: str = "your finger"
        bottom_label: str = "the table"
        gap_label: str = "never zero"
        show_forces: bool = True

    def build(self, scene, p, duration):
        xs = np.arange(-6.0, 6.01, 1.2)
        top = VGroup(*[_atom(brand.PAPER).move_to([x, 0, 0]) for x in xs])
        bot = VGroup(*[_atom(brand.GLOW).move_to([x + 0.6, 0, 0]) for x in xs])

        gap = ValueTracker(3.0)       # distance between the two rows' centres
        base_y = -1.5
        rng = np.random.default_rng(5)
        phases = rng.uniform(0, 2 * np.pi, (2, len(xs)))
        clock = {"t": 0.0}

        def place(group, dt):
            clock["t"] += dt / 2      # two updaters share the clock
            g = gap.get_value()
            closeness = np.clip((2.0 - g) / 0.7, 0, 1)   # 0 far ... 1 at the closest point
            for row, (grp, y) in enumerate(((top, base_y + g), (bot, base_y))):
                for k, a in enumerate(grp):
                    j = 0.04 * np.array([np.sin(8 * clock["t"] + phases[row, k]),
                                         np.cos(6 * clock["t"] + phases[row, k]), 0])
                    a.move_to([xs[k] + (0.6 if row else 0), y, 0] + j)
                    a.ring.set_stroke(brand.EMBER if closeness > 0.05 else (brand.GLOW if row else brand.PAPER),
                                      1.5 + 2.5 * closeness, 0.45 + 0.5 * closeness)

        top.add_updater(place)
        bot.add_updater(place)

        lt = Text(p.top_label, font=brand.SANS, color=brand.PAPER).scale(0.42)
        lb = Text(p.bottom_label, font=brand.SANS, color=brand.GLOW).scale(0.42)
        lt.add_updater(lambda m: m.move_to([0, base_y + gap.get_value() + 0.95, 0]))
        lb.add_updater(lambda m: m.move_to([0, base_y - 0.95, 0]))

        scene.play(FadeIn(bot), FadeIn(top), FadeIn(lt), FadeIn(lb), run_time=min(0.8, duration * 0.12))

        approach = duration * 0.38
        scene.play(gap.animate.set_value(1.32), run_time=approach, rate_func=rate_functions.ease_in_quad)

        extras = VGroup()
        if p.show_forces:
            ups = VGroup(*[Arrow([x, base_y + 1.32 + 0.15, 0], [x, base_y + 1.32 + 0.95, 0], buff=0,
                                 color=brand.EMBER, stroke_width=4, max_tip_length_to_length_ratio=0.3)
                           for x in xs[2:-2:2]])
            downs = VGroup(*[Arrow([x + 0.6, base_y - 0.15, 0], [x + 0.6, base_y - 0.95, 0], buff=0,
                                   color=brand.EMBER, stroke_width=4, max_tip_length_to_length_ratio=0.3)
                             for x in xs[2:-2:2]])
            extras.add(ups, downs)

        seam = DashedLine([-6.8, 0, 0], [6.8, 0, 0], dash_length=0.12).set_stroke(brand.EMBER, 2, 0.7)
        seam.add_updater(lambda m: m.set_y(base_y + gap.get_value() / 2))
        gl = Text(p.gap_label, font=brand.SANS, weight="BOLD", color=brand.EMBER).scale(0.42)
        gl_bg = BackgroundRectangle(gl, color=brand.NIGHT, fill_opacity=0.85, buff=0.12)
        tag = VGroup(gl_bg, gl)
        tag_x = min(3.6, frame_w() / 2 - tag.width / 2 - 0.3)
        tag.add_updater(lambda m: m.move_to([tag_x, base_y + gap.get_value() / 2, 0]))
        extras.add(seam, tag)

        # push back: bounce to a slightly larger gap and keep trembling there
        scene.play(
            gap.animate(rate_func=rate_functions.there_and_back_with_pause).set_value(1.2),
            FadeIn(extras),
            run_time=min(1.2, duration * 0.18),
        )
        scene.play(gap.animate.set_value(1.36), run_time=min(0.6, duration * 0.08), rate_func=rate_functions.ease_out_sine)

        rest = duration - getattr(scene.renderer, "time", 0)
        if rest > 0.2:
            scene.play(
                scene.camera.frame.animate(rate_func=linear).scale(0.82).move_to([0, base_y + 0.6, 0]),
                gap.animate(rate_func=rate_functions.wiggle).set_value(1.3),
                run_time=rest,
            )

def label(text: str, size: float = 0.5, color: str = INK, bold: bool = True, max_width: float | None = None,
          t2c: dict | None = None) -> Text:
    t = Text(text, font=brand.SANS, weight=BOLD if bold else "NORMAL", color=color, t2c=t2c or {}).scale(size)
    mw = max_width or fw() * 0.86
    if t.width > mw:

def wrap_label(text: str, size: float, color: str = INK, chars: int = 22, max_width: float | None = None,
               bold: bool = True, t2c: dict | None = None) -> VGroup:
    """Multi-line centred text (wraps on words). t2c colours words: {"forget": "#EF476F"}."""
    import textwrap

    lines = textwrap.wrap(text, chars) or [""]
    g = VGroup(*[label(l, size, color, bold, max_width,
                       {k: v for k, v in (t2c or {}).items() if k and k in l}) for l in lines]).arrange(DOWN, buff=0.12 * size / 0.5)
    mw = max_width or fw() * 0.86
    if g.width > mw:
        g.scale_to_fit_width(mw)
    return g

                       for a in np.linspace(0, 2 * np.pi, 9)[:-1]])
        sun.move_to([W * 0.32, fh() * 0.32, 0])
        for x, h in ((-W * 0.34, 2.4), (-W * 0.18, 1.8)):
            trunk = Rectangle(width=0.22, height=h * 0.5).set_stroke(width=0).set_fill("#7B4B2A", 1).move_to([x, y + h * 0.25, 0])
            crown = Circle(radius=h * 0.33).set_stroke(width=0).set_fill(pal["d"], 1).move_to([x, y + h * 0.62, 0])
            g.add(trunk, crown)
        cloud = VGroup(*[Circle(radius=r).set_stroke(width=0).set_fill(WHITE, 0.9).shift(RIGHT * dx + UP * dy)
                         for r, dx, dy in ((0.35, 0, 0), (0.45, 0.45, 0.12), (0.32, 0.9, 0))]).move_to([-W * 0.05, fh() * 0.36, 0])
        g.add(sun, cloud)
    elif kind == "lab":
        bench = Rectangle(width=W * 0.5, height=0.16).set_stroke(width=0).set_fill(INK, 0.6).move_to([W * 0.15, y + 1.1, 0])
        g.add(bench)
        for i, col in enumerate((pal["a"], pal["c"], pal["d"])):

            body = Polygon([x - 0.28, y + 1.18, 0], [x + 0.28, y + 1.18, 0], [x + 0.1, y + 1.75, 0], [x - 0.1, y + 1.75, 0])
            body.set_stroke(INK, 4).set_fill(col, 0.85)
            neck = Rectangle(width=0.2, height=0.35).set_stroke(INK, 4).set_fill(WHITE, 0.6).move_to([x, y + 1.92, 0])
            g.add(body, neck)
        board = RoundedRectangle(width=2.2, height=1.3, corner_radius=0.08).set_stroke("#7B4B2A", 6).set_fill(WHITE, 1)
        board.move_to([-W * 0.28, y + 3.0, 0])
        scribble = VGroup(*[Line(board.get_left() + RIGHT * 0.3 + UP * k, board.get_left() + RIGHT * (0.9 + 0.5 * (k % 2)) + UP * k)
                            for k in (0.3, 0.0, -0.3)]).set_stroke(pal["c"], 4)
        g.add(board, scribble)
    elif kind == "street":
        for i, (x, h, col) in enumerate(((-W * 0.38, 3.2, pal["c"]), (-W * 0.16, 2.4, pal["a"]), (W * 0.2, 3.6, pal["b"]), (W * 0.42, 2.6, pal["d"]))):

        g.add(stars, moon)
    g.set_z_index(-10)

def _round(mob) -> None:
    """Round line caps where this Manim version supports it."""
    try:
        from manim import CapStyleType
        for m in mob.family_members_with_points():
            m.set_cap_style(CapStyleType.ROUND)
    except Exception:  # noqa: BLE001 - purely cosmetic
        pass


# ---- the stick figure -----------------------------------------------------------------
FACES = ["neutral", "happy", "surprised", "confused", "scared", "thinking", "sleepy", "sad"]


class Stick:
    """An animated stick figure. Animate it through its trackers:

        x, y (feet position), walk (0 = still, 1 = walking), arm_l / arm_r (radians from
        straight down, positive = forward), tilt (head), jump (height), face (index in FACES),
        facing (+1 right, -1 left).

    `mob` is an always-redrawn VGroup; add it to the scene once.
    """

    def __init__(self, x: float = 0.0, y: float | None = None, s: float | None = None,
                 accent: str = "#FB8500", face: str = "neutral", facing: int = 1):
        self.s = (s or 1.0) * unit()
        self.accent = accent
        self.x = ValueTracker(x)
        self.y = ValueTracker(floor_y() if y is None else y)
        self.walk = ValueTracker(0.0)
        self.arm_l = ValueTracker(-0.18)
        self.arm_r = ValueTracker(0.18)
        self.tilt = ValueTracker(0.0)
        self.jump = ValueTracker(0.0)
        self.face = ValueTracker(FACES.index(face))
        self.facing = ValueTracker(facing)
        self.phase = 0.0
        self.mob = always_redraw(self._draw)
        clock = VMobject()   # invisible driver for the walk cycle

        def tick(m, dt):
            self.phase += dt * 9.0 * self.walk.get_value()
        clock.add_updater(tick)
        self.clock = clock

    def set_face(self, name: str) -> None:
        self.face.set_value(FACES.index(name))

    def head_top(self) -> np.ndarray:
        s = self.s
        return np.array([self.x.get_value(), self.y.get_value() + self.jump.get_value() + 2.85 * s, 0])

    def _draw(self) -> VGroup:
        s = self.s
        x, y = self.x.get_value(), self.y.get_value() + self.jump.get_value()
        f = 1 if self.facing.get_value() >= 0 else -1
        w = self.walk.get_value()
        sw = np.sin(self.phase) * 0.55 * w
        lw = 9 * s
        hip = np.array([x, y + 1.1 * s, 0])
        neck = np.array([x, y + 2.05 * s, 0])
        sh = np.array([x, y + 1.88 * s, 0])

        def limb(start, ang, length):
            return start + np.array([np.sin(ang) * length * f, -np.cos(ang) * length, 0])

        bob = abs(np.sin(self.phase)) * 0.05 * s * w
        hip, neck, sh = hip + UP * bob, neck + UP * bob, sh + UP * bob
        legs = VGroup(Line(hip, limb(hip, sw + 0.1, 1.15 * s)), Line(hip, limb(hip, -sw - 0.1, 1.15 * s)))
        body = Line(hip, neck)
        al = self.arm_l.get_value() - sw * 0.9 * (1 if w else 0)
        ar = self.arm_r.get_value() + sw * 0.9 * (1 if w else 0)
        arms = VGroup(Line(sh, limb(sh, al, 0.85 * s)), Line(sh, limb(sh, ar, 0.85 * s)))
        figure = VGroup(legs, body, arms).set_stroke(INK, lw)
        _round(figure)
        scarf = VGroup(Line(neck + LEFT * 0.17 * s, neck + RIGHT * 0.17 * s),
                       Line(neck + RIGHT * 0.1 * s * f, neck + np.array([-0.12 * s * f - sw * 0.08, -0.38 * s, 0]))).set_stroke(self.accent, 11 * s)
        head_c = neck + UP * 0.42 * s
        head = Circle(radius=0.40 * s).set_fill(SKIN, 1).set_stroke(INK, lw * 0.95).move_to(head_c)
        face = self._face(head_c, s, f)
        face.rotate(self.tilt.get_value() * f, about_point=head_c)
        return VGroup(figure, scarf, head, face)

    def _face(self, c, s, f) -> VGroup:
        kind = FACES[int(round(self.face.get_value())) % len(FACES)]
        ex = c + np.array([0.06 * s * f, 0.05 * s, 0])
        eyes = VGroup(*[Dot(ex + np.array([dx * s * f, 0, 0]), radius=0.045 * s, color=INK) for dx in (0.0, 0.19)])
        mc = c + np.array([0.14 * s * f, -0.15 * s, 0])
        lw = 5 * s
        if kind == "happy":
            mouth = Arc(radius=0.12 * s, start_angle=-np.pi * 0.85, angle=np.pi * 0.7, arc_center=mc + UP * 0.08 * s).set_stroke(INK, lw)
        elif kind == "surprised":
            mouth = Circle(radius=0.06 * s).set_stroke(INK, lw).move_to(mc)
        elif kind == "scared":
            mouth = Ellipse(width=0.16 * s, height=0.11 * s).set_stroke(INK, lw).move_to(mc)
            eyes = VGroup(*[Circle(radius=0.06 * s).set_stroke(INK, 3 * s).set_fill(WHITE, 1).move_to(e.get_center()) for e in eyes],
                          *[Dot(e.get_center(), radius=0.025 * s, color=INK) for e in eyes])
        elif kind == "confused":
            mouth = VMobject().set_points_smoothly([mc + LEFT * 0.1 * s, mc + UP * 0.04 * s, mc + RIGHT * 0.1 * s + DOWN * 0.02 * s]).set_stroke(INK, lw)
            brow = Line(ex + np.array([0.12 * s * f, 0.12 * s, 0]), ex + np.array([0.27 * s * f, 0.17 * s, 0])).set_stroke(INK, 4 * s)
            mouth = VGroup(mouth, brow)
        elif kind == "thinking":
            eyes = VGroup(*[Dot(e.get_center() + UP * 0.05 * s + RIGHT * 0.03 * s * f, radius=0.045 * s, color=INK) for e in eyes])
            mouth = Line(mc + LEFT * 0.06 * s, mc + RIGHT * 0.08 * s).set_stroke(INK, lw)
        elif kind == "sleepy":
            eyes = VGroup(*[Line(e.get_center() + LEFT * 0.05 * s, e.get_center() + RIGHT * 0.05 * s).set_stroke(INK, 4 * s) for e in eyes])
            mouth = Line(mc + LEFT * 0.05 * s, mc + RIGHT * 0.05 * s).set_stroke(INK, lw)
        elif kind == "sad":
            mouth = Arc(radius=0.12 * s, start_angle=np.pi * 0.15, angle=np.pi * 0.7, arc_center=mc + DOWN * 0.1 * s).set_stroke(INK, lw)
        else:
            mouth = Line(mc + LEFT * 0.08 * s, mc + RIGHT * 0.08 * s).set_stroke(INK, lw)
        return VGroup(eyes, mouth)


def add_stick(scene, stick: Stick) -> Stick:
    scene.add(stick.clock, stick.mob)
    return stick

def brain_shape(size: float = 2.0, pal: dict | None = None, color: str = "#FF8FAB", groove: str = "#E05780") -> VGroup:
    r = size / 2
    lobes = VGroup(*[Circle(radius=r * k).set_stroke(width=0).set_fill(color, 1).shift(np.array([dx, dy, 0]) * r)
                     for k, dx, dy in ((0.5, -0.45, 0.15), (0.52, 0.0, 0.32), (0.5, 0.45, 0.15), (0.46, -0.32, -0.25), (0.46, 0.32, -0.25), (0.5, 0, -0.02))])
    lw = 5 * size / 2
    grooves = VGroup(
        VMobject().set_points_smoothly([[0, 0.78 * r, 0], [-0.08 * r, 0.3 * r, 0], [0.06 * r, -0.2 * r, 0], [0, -0.6 * r, 0]]),
        *[VMobject().set_points_smoothly([[sx * 0.62 * r, 0.42 * r, 0], [sx * 0.32 * r, 0.3 * r, 0], [sx * 0.42 * r, 0.02 * r, 0], [sx * 0.2 * r, -0.05 * r, 0]]) for sx in (-1, 1)],
        *[VMobject().set_points_smoothly([[sx * 0.7 * r, -0.12 * r, 0], [sx * 0.5 * r, -0.32 * r, 0], [sx * 0.25 * r, -0.4 * r, 0]]) for sx in (-1, 1)],
    ).set_stroke(groove, lw)
    return VGroup(lobes, grooves)


def bubble(content, kind: str = "thought", pad: float = 0.25, pal: dict | None = None) -> VGroup:
    """A white bubble around `content` (a mobject). kind: thought | speech."""
    w, h = content.width + 2 * pad, content.height + 2 * pad
    body = RoundedRectangle(width=max(w, h * 1.1), height=h, corner_radius=min(h / 2, 0.5)).set_stroke(INK, 5).set_fill(WHITE, 1)
    body.move_to(content.get_center())
    tail = VGroup()
    if kind == "thought":
        tail = VGroup(Circle(radius=0.11).set_stroke(INK, 4).set_fill(WHITE, 1).next_to(body, DOWN, buff=0.06).shift(LEFT * body.width * 0.25),
                      Circle(radius=0.07).set_stroke(INK, 4).set_fill(WHITE, 1).next_to(body, DOWN, buff=0.3).shift(LEFT * body.width * 0.32))
    else:
        tri = Polygon([-0.15, 0, 0], [0.15, 0, 0], [-0.25, -0.35, 0]).set_stroke(INK, 5).set_fill(WHITE, 1)
        tri.next_to(body, DOWN, buff=-0.06).shift(LEFT * body.width * 0.2)
        cover = Rectangle(width=0.28, height=0.08).set_stroke(width=0).set_fill(WHITE, 1).move_to(tri.get_top() + DOWN * 0.04)
        tail = VGroup(tri, cover)
    return VGroup(tail, body, content.copy())


def card(w: float, h: float, color: str = WHITE, radius: float = 0.22, shadow: bool = True) -> VGroup:
    face = RoundedRectangle(width=w, height=h, corner_radius=radius).set_stroke(width=0).set_fill(color, 1)
    if not shadow:
        return VGroup(face)
    sh = face.copy().set_fill(INK, 0.12).shift(DOWN * 0.08 + RIGHT * 0.05)
    return VGroup(sh, face)


def pill(text: str, color: str, size: float = 0.42, text_color: str = WHITE) -> VGroup:
    t = label(text, size, text_color)
    p = RoundedRectangle(width=t.width + 0.6 * size / 0.42, height=t.height + 0.36 * size / 0.42,
                         corner_radius=(t.height + 0.36) / 2).set_stroke(width=0).set_fill(color, 1)
    return VGroup(p, t.move_to(p))


def caption_bar(text: str, pal: dict) -> VGroup:
    """A headline pill at the top of the frame (used by several templates)."""
    t = wrap_label(text, 0.62 if vertical() else 0.58, WHITE, chars=20 if vertical() else 38)
    bg = RoundedRectangle(width=t.width + 0.6, height=t.height + 0.4, corner_radius=0.25).set_stroke(width=0).set_fill(INK, 0.88)
    g = VGroup(bg, t.move_to(bg))
    g.move_to([0, fh() / 2 - g.height / 2 - fh() * (0.10 if vertical() else 0.07), 0])
    return g


def rest_of(scene, duration: float) -> float:
    return duration - getattr(scene.renderer, "time", 0.0)


def blobs(pal: dict, seed: int = 0, n: int = 5) -> VGroup:
    """Large soft circles drifting slowly in the background (gives plain backgrounds some life)."""
    rng = np.random.default_rng(seed)
    g = VGroup()
    for i in range(n):
        c = Circle(radius=rng.uniform(0.9, 2.0)).set_stroke(width=0)
        c.set_fill([pal["a"], pal["b"], pal["c"], pal["d"]][i % 4], 0.10)
        c.move_to([rng.uniform(-fw() / 2, fw() / 2), rng.uniform(-fh() / 2, fh() / 2), 0])
        c.v = np.array([rng.uniform(-0.12, 0.12), rng.uniform(-0.08, 0.08), 0])
        g.add(c)

    def drift(m, dt):
        for c in m:
            c.shift(c.v * dt)
    g.add_updater(drift)
    g.set_z_index(-15)
    return g


def person(color: str = INK, size: float = 0.6) -> VGroup:
    """A simple person icon (head + rounded body) for crowds and diagrams."""
    head = Circle(radius=size * 0.22).set_stroke(width=0).set_fill(color, 1).shift(UP * size * 0.32)
    body = RoundedRectangle(width=size * 0.62, height=size * 0.5, corner_radius=size * 0.24).set_stroke(width=0).set_fill(color, 1)
    body.shift(DOWN * size * 0.18)
    return VGroup(head, body)


class Budget:
    """Spreads a template's animations over the beat so the clip never runs longer than its voice.

    t(share, cap) -> seconds: `share` of the whole beat, but at most `cap` seconds.
    Keep the shares of one template below ~0.8 in total; the rest is a slow camera drift.
    """

    def __init__(self, duration: float):
        self.d = duration

    def t(self, share: float, cap: float) -> float:
        return max(0.15, min(cap, self.d * share))


def flat_bg(scene, pal: dict) -> None:
    """Gradient background with drifting blobs, no floor."""
    scene.add(background(pal, floor=False), blobs(pal, getattr(scene, "seed", 0)))


def drift_camera(scene, duration: float, scale: float = 0.96):
    from manim import linear as _lin

    rest = rest_of(scene, duration)
    if rest > 0.15:
        scene.play(scene.camera.frame.animate(rate_func=_lin).scale(scale), run_time=rest)


def grid_shape(n: int, ratio: float) -> tuple[int, int]:
    """Columns and rows for n items: as close to `ratio` (cols / rows) as possible, few empty slots."""
    best = None
    for cols in range(1, n + 1):
        rows = -(-n // cols)
        score = 0.15 * (rows * cols - n) + abs(np.log((cols / rows) / ratio))
        if best is None or score < best[0]:
            best = (score, cols, rows)
    return best[1], best[2]


def center_last_row(group: VGroup, cols: int) -> None:
    """arrange_in_grid leaves a short last row on the left; move it to the middle."""
    n = len(group)
    left = n % cols
    if left and n > cols:
        row = group[n - left:]
        full = group[n - left - cols:n - left]
        VGroup(*row).set_x(VGroup(*full).get_x())


def fit_between(mob, top: float, bottom: float, max_width: float | None = None):
    """Scale down (never up) and centre a mobject vertically between two y values."""
    if mob.height > top - bottom:
        mob.scale_to_fit_height(top - bottom)
    if max_width and mob.width > max_width:
        mob.scale_to_fit_width(max_width)
    return mob.set_y((top + bottom) / 2)


def parse_pair(item: str, default_left: str = "") -> tuple[str, str]:
    """'icon|text' or '1904|text' -> (left, right). Without '|' the left part is default_left."""
    if "|" in item:
        a, b = item.split("|", 1)
        return a.strip(), b.strip()
    return default_left, item.strip()

"""Join beat clips and voice into the final video, plus subtitles and chapters."""

from __future__ import annotations

import subprocess
import textwrap
from pathlib import Path


def _ts_srt(t: float) -> str:
    ms = int(round(t * 1000))
    h, ms = divmod(ms, 3_600_000)
    m, ms = divmod(ms, 60_000)
    s, ms = divmod(ms, 1000)
    return f"{h:02d}:{m:02d}:{s:02d},{ms:03d}"


def _ts_chapter(t: float) -> str:
    t = int(t)
    h, rem = divmod(t, 3600)
    m, s = divmod(rem, 60)
    return f"{h}:{m:02d}:{s:02d}" if h else f"{m:02d}:{s:02d}"


def build_audio(voice_files: list[Path], durations: list[float], out: Path) -> None:
    """Each voice clip is padded with silence to its beat length, then all are joined."""
    inputs, chains = [], []
    for i, (f, d) in enumerate(zip(voice_files, durations)):
        inputs += ["-i", str(f)]
        chains.append(f"[{i}:a]aresample=48000,apad,atrim=0:{d:.3f},asetpts=PTS-STARTPTS[a{i}]")
    joined = "".join(f"[a{i}]" for i in range(len(voice_files)))
    graph = ";".join(chains) + f";{joined}concat=n={len(voice_files)}:v=0:a=1[out]"
    subprocess.run(
        ["ffmpeg", "-v", "error", "-y", *inputs, "-filter_complex", graph, "-map", "[out]",
         "-ac", "2", str(out)],
        check=True,
    )


def build_video(clips: list[Path], audio: Path, out: Path, loudnorm: bool = True) -> None:
    listing = out.with_suffix(".txt")
    listing.write_text("".join(f"file '{c.resolve()}'\n" for c in clips), encoding="utf-8")
    af = ["-af", "loudnorm=I=-14:TP=-1.5:LRA=11"] if loudnorm else []
    subprocess.run(
        ["ffmpeg", "-v", "error", "-y", "-f", "concat", "-safe", "0", "-i", str(listing),
         "-i", str(audio), "-map", "0:v", "-map", "1:a", "-c:v", "copy", *af,
         "-c:a", "aac", "-b:a", "192k", "-shortest", "-movflags", "+faststart", str(out)],
        check=True,
    )
    listing.unlink(missing_ok=True)


def write_srt(texts: list[str], durations: list[float], out: Path) -> None:
    t, blocks = 0.0, []
    for i, (txt, d) in enumerate(zip(texts, durations), 1):
        lines = textwrap.wrap(txt, 42)
        blocks.append(f"{i}\n{_ts_srt(t)} --> {_ts_srt(t + d - 0.05)}\n" + "\n".join(lines) + "\n")
        t += d
    out.write_text("\n".join(blocks), encoding="utf-8")


def write_chapters(chapters: list[str | None], durations: list[float], out: Path) -> None:
    t, rows = 0.0, []
    for name, d in zip(chapters, durations):
        if name:
            rows.append(f"{_ts_chapter(t)} {name}")
        t += d
    if rows and not rows[0].startswith("00:00"):
        rows.insert(0, "00:00 Intro")
    out.write_text("\n".join(rows) + ("\n" if rows else ""), encoding="utf-8")


def extract_thumbs(video: Path, starts: list[float], durations: list[float], out_dir: Path, n: int = 5) -> None:
    """Grab one frame from the middle of the n longest beats as thumbnail candidates."""
    out_dir.mkdir(parents=True, exist_ok=True)
    order = sorted(range(len(durations)), key=lambda i: -durations[i])[:n]
    for rank, i in enumerate(sorted(order), 1):
        t = starts[i] + durations[i] * 0.6
        subprocess.run(
            ["ffmpeg", "-v", "error", "-y", "-ss", f"{t:.2f}", "-i", str(video), "-frames:v", "1",
             str(out_dir / f"thumb_{rank}_beat{i + 1:03d}.png")],
            check=True,
        )

"""Project file format (YAML) and its validation."""

from __future__ import annotations

from pathlib import Path
from typing import Any, Literal

import yaml
from pydantic import BaseModel, Field, field_validator, model_validator

from beatframe.formats import DEFAULT_FORMAT, FormatName, VideoFormat, get_format


class Voice(BaseModel):
    provider: Literal["edge", "kokoro", "files", "silent"] = "edge"
    name: str = "en-US-AndrewMultilingualNeural"   # edge: en-US-...Neural | kokoro: am_michael, bm_george, af_heart...
    rate: str = "+0%"                  # base speaking rate, e.g. "-5%"
    pitch: str = "+0Hz"                # base pitch (edge only), e.g. "-2Hz"
    style: Literal["auto", "flat"] = "auto"   # auto = speed/pitch follow each sentence (hooks, questions, punchlines)
    expressiveness: float = 1.0        # 0 = flat ... 1 = normal ... 1.5 = very lively
    upgrade: bool = True               # swap old flat edge voices (Christopher, Andrew...) for the Multilingual ones
    files_dir: str | None = None       # provider=files: folder with 001.mp3, 002.mp3, ...
    words_per_second: float = 2.4      # provider=silent: estimated pace

    @model_validator(mode="after")
    def _kokoro_name(self) -> "Voice":
        if self.provider == "kokoro" and "-" in self.name:   # an edge name left over: pick a kokoro voice
            self.name = "am_michael"
        return self


class Audio(BaseModel):
    """Background music and sound effects under the voice."""
    music: str = "auto"                # auto (generated, royalty-free) | none | a file in the project folder ("music.mp3")
    mood: Literal["auto", "mystery", "wonder", "epic", "tense", "calm"] = "auto"
    music_volume: float = 0.5          # 0..1 (music is ducked under the voice automatically)
    sfx: bool = True                   # soft whoosh on scene changes, a low hit on chapter starts
    sfx_volume: float = 0.5


class Beat(BaseModel):
    text: str
    scene: str
    params: dict[str, Any] = Field(default_factory=dict)
    chapter: str | None = None         # start a YouTube chapter at this beat
    pad: float = 0.35                  # seconds of breathing room after the voice
    min_duration: float = 2.0


class Video(BaseModel):
    format: FormatName = DEFAULT_FORMAT   # long (16:9, 1920x1080) | short (9:16, 1080x1920)
    width: int | None = None              # optional override; normally taken from `format`
    height: int | None = None
    fps: int = 30

    @model_validator(mode="after")
    def _size_matches_format(self) -> "Video":
        if (self.width is None) != (self.height is None):
            raise ValueError("video.width and video.height must be given together (or both left out)")
        if self.width is not None and (self.height > self.width) != get_format(self.format).vertical:
            raise ValueError(f"video size {self.width}x{self.height} does not match format '{self.format}'")
        return self

    @property
    def spec(self) -> VideoFormat:
        return get_format(self.format)

    def size(self, preview: bool = False) -> tuple[int, int]:
        """Pixel size to render at. Previews always use the format's 480p size."""
        if preview or self.width is None:
            return self.spec.size(preview)
        return self.width, self.height

    def with_format(self, name: str) -> "Video":
        """The same settings in another format (an explicit size only survives if the format is unchanged)."""
        if get_format(name).name == self.format:
            return self
        return Video(format=get_format(name).name, fps=self.fps)


class Project(BaseModel):
    title: str
    description: str = ""              # YouTube description (chapters are added automatically)
    tags: list[str] = Field(default_factory=list)
    voice: Voice = Voice()
    audio: Audio = Audio()
    video: Video = Video()
    beats: list[Beat]

    @field_validator("beats")
    @classmethod
    def _not_empty(cls, v: list[Beat]) -> list[Beat]:
        if not v:
            raise ValueError("a project needs at least one beat")
        return v


def parse_project(text: str) -> Project:
    data = yaml.safe_load(text)
    if not isinstance(data, dict):
        raise ValueError("the script must be a YAML mapping with at least 'title' and 'beats'")
    return Project.model_validate(data)


def load_project(path: str | Path) -> Project:
    return parse_project(Path(path).read_text(encoding="utf-8"))


def dump_project(project: Project) -> str:
    data = project.model_dump(mode="json", exclude_defaults=True)
    data.setdefault("title", project.title)
    data["beats"] = [b.model_dump(mode="json", exclude_defaults=True) | {"text": b.text, "scene": b.scene}
                     for b in project.beats]
    return yaml.safe_dump(data, sort_keys=False, allow_unicode=True, width=100)

# Beatframe

Narration script in, animated documentary out.

You write a YAML file: each **beat** is one spoken sentence plus the scene template that
should play under it. Beatframe makes the voice, renders every beat with Manim at exactly
the length of its voice, and joins everything into one video with subtitles, chapters and
thumbnail candidates.

```
script.yaml ─► voice (TTS) ─► per-beat Manim clips (cached, parallel) ─► final.mp4
                                                                       ├─ subtitles.srt
                                                                       ├─ chapters.txt
                                                                       └─ thumbs/
```

## Install (Ubuntu)

```bash
sudo apt install ffmpeg libpango1.0-dev libcairo2-dev pkg-config python3-venv \
    python3-dev build-essential libgl1-mesa-dev
cd beatframe
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Studio (web app)

```bash
beatframe web          # opens http://127.0.0.1:8000
```

Pick **Short** (9:16, 1080×1920 - Shorts, Reels, TikTok) or **Long** (16:9, 1920×1080 - YouTube),
paste a script, watch it render with live progress (stage, beat n / total, percent), edit beats (text, scene, params,
add / delete / reorder) and re-render only what changed, then publish: download files for
manual upload, or upload straight to YouTube (title, description with chapters, tags,
subtitles, thumbnail, visibility, schedule) through the YouTube Data API.

YouTube setup: create a Google Cloud project, enable YouTube Data API v3, add yourself
as a test user on the OAuth consent screen, create an OAuth client of type **Desktop app**
and save its JSON as `~/.beatframe/client_secret.json`. Until the project passes YouTube's
API audit, API uploads are locked to Private.

Built with FastAPI + Jinja + htmx; renders and uploads run on a background worker thread.

template code changed are rendered again.

| `stick_doorway` | walks from one room to the next; the idea it carried can vanish |
| `stick_compare` | A vs B with a stick figure, icon and check/cross for each |
| `stick_talk` | two stick figures, each line in a speech bubble |
| `stick_crowd` | a crowd where some people light up ("1 in 10") |
| `stat_pop` | a number counts up on a card, with icon, caption and source |
| `icon_list` | 2-4 numbered icon cards (`icon|text`) |
| `timeline` | 2-5 dated events (`year|what happened`) |
| `bar_chart` | bars grow to their values, one highlighted |
| `myth_fact` | the myth is crossed out, the fact gets a check |
| `kinetic_text` | words pop in, key words get colour blocks |
| `body_map` | body outline, one part glows with a label |
| `process_cycle` | 3-5 steps light up in order, optionally looping back |
| `brain_light` | big brain, one region lights up |

`projects/bright-demo/` uses every one of them. `beatframe templates` lists their settings.

Add a template: create `beatframe/templates/<name>.py` with a `Template` subclass
(`name`, a pydantic `Params`, and `build(scene, p, duration)`). It is picked up automatically.

Formats: long frames are 14.2 × 8 units. In short mode a template with `vertical_width = 8.0`
gets an 8 × 14.2 frame and lays itself out with the helpers in `templates/base.py`
(`frame_w()`, `frame_h()`, `width_ratio()`, `fit()`, `keep_inside_x()`); title_card, statement,
source_card, electron_repulsion and scale_zoom work this way. Templates drawn for 16:9 set
`vertical_width` to the part of their drawing that must stay visible (default 14.2), and the
portrait frame is widened to that. Sizes live in one place: `formats.py`.

## Layout

```
beatframe/
├── brand.py          colours, fonts
├── formats.py        Short / Long: sizes and frame units (the only place that knows them)
├── schema.py         YAML format (pydantic)
├── tts.py            voice providers
├── render.py         per-beat Manim render, cache, workers
├── assemble.py       ffmpeg join, loudness, SRT, chapters, thumbnails
├── pipeline.py       the whole run
├── cli.py            command line
└── templates/        one file per scene template
projects/touch/touch.yaml   example: opening of the "touch" video
```
